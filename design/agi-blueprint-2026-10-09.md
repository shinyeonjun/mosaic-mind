# AGI 시작점 설계도 (2026-10-09)

바탕: `design/direction-2026-10-09.md`(방향), `design/mk1-v2-spec.md`(명세), `design/neuroscience-review-2026-10-09.md`(뇌과학 1차 조사). 이 문서는 (1) 뇌 부위가 하는 **계산**, (2) **지능의 정의**, (3) 이상적인 구조와 MK1의 빈칸, (4) 단계별 계획과 통과 기준을 정한다.

## 1. 뇌 부위의 계산 (입력 → 출력, 알고리즘, 학습 규칙, 시간 척도)

| 부위 | 입력 → 출력 | 알고리즘 (현재 가장 유력한 설명) | 학습 | 시간 척도 | 근거 |
|---|---|---|---|---|---|
| 신피질 기둥들 | 감각·다른 영역 → 예측과 예측 오차 | 계층 예측 모델. 위는 예측, 아래는 오차만 올림. 여러 기둥이 각자 모델을 갖고 투표 | 국소 오차로 천천히 | 느림 | Rao & Ballard, Friston, Hawkins |
| 시상 | 한 피질 영역 → 다른 영역 | **라우팅·관문**. 주 신호(driver)와 조절 신호(modulator)를 나눔. 피질-피질 직접 경로와 시상 경유 경로를 기저핵이 열고 닫음 | — | 빠름 | Sherman, Dehghani & Wimmer, eLife 2024 |
| 기저핵 | 상황 → 선택(행동, 작업기억 갱신) | 행동자-비평자 강화학습. 무엇을 할지, 무엇을 작업기억에 넣을지 관문 | 도파민 보상 예측 오차 | 중간 | O'Reilly & Frank (PBWM) |
| 전전두엽 | 목표·규칙 → 다른 영역의 처리에 편향 | **작업기억에 과제 규칙(task set)을 유지**하고, 다른 영역의 처리를 위에서 조절. 앞쪽일수록 추상적인 규칙 (계층 제어) | 기저핵 관문을 통해 | 초~분 | Miller & Cohen, Koechlin, Badre (일부 배경지식, 원문 확인 필요) |
| 해마 + 내후각피질 | 경험 → 빠른 일화 기억, 구조 지도 | **구조와 내용을 분리**. 내후각은 재사용되는 구조의 기저(격자세포), 해마는 그 구조에 구체적 감각 내용을 묶음. 그래서 새 환경에도 구조가 일반화됨 | 한 번에 빠르게 | 빠름 | Whittington 외 (TEM, Cell 2020) |
| 해마 → 신피질 (수면) | 일화 → 구조화된 지식 | **재생**: 저장한 경험을 다른 경험과 섞어서 신피질에 반복 학습. 기존 틀과 맞으면 빨리 굳음 | 재생 | 시간~일 | Kumaran·Hassabis·McClelland 2016, Tse 2007 |
| 소뇌 | 명령의 복사본 → 예상 결과 | **순방향 모델**: 행동의 결과를 미리 예측하고, 실제와의 오차로 배움. 바깥 세계를 거치지 않는 내부 시뮬레이션. 인지 기능으로의 확장은 아직 열린 문제 | 오차(등반섬유) 지도학습 | 빠름 | Popa & Ebner, 소뇌 순방향 모델 리뷰 |
| 안와전두피질 | 증거 → 확신 | P(내 선택이 맞음 \| 증거). 결정과 분리된 판독 | — | 빠름 | Kepecs 2008, Lak 2014 |
| 신경조절물질 | 전역 상태 → 학습 파라미터 | 도파민 = 보상 예측 오차, 아세틸콜린 = 예상된 불확실성(학습률), 노르에피네프린 = 예상 못 한 불확실성(초기화, 탐색), 세로토닌 = 시간 범위 | — | 느림 | Doya 2002, Yu & Dayan 2005 |

## 2. 지능의 정의 (무엇을 만들고 무엇으로 잴지)

- **Chollet (2019)**: 지능은 "가진 기술"이 아니라 **기술을 얻는 효율**이다. 사전 지식(priors)과 경험(experience)을 얼마나 적게 써서, 얼마나 먼 일반화(generalization difficulty)에 도달하느냐다. 사전 지식이나 데이터를 무한히 넣으면 일반화 없이도 점수는 높일 수 있다. 그래서 둘을 통제하고 재야 한다.
  - **우리 측정에 주는 뜻**: 최종 점수만이 아니라 **새 과제의 학습 곡선**(예시 몇 개 만에 몇 점까지)을 잰다. LLM의 거대한 사전 지식과 공정하게 비교하려면 이게 핵심 지표다.
- **Lake, Ullman, Tenenbaum, Gershman (BBS 2017)**: 사람처럼 배우는 기계의 재료는 다섯 가지다. 직관 물리, 직관 심리, **조합성**, **배우는 법 배우기**, **인과 모델**.
- **LeCun (2022, 입장 논문)**: 자율 지능의 모듈 여섯 개. **구성기**(다른 모듈을 과제에 맞게 설정), 지각, **세계 모델**(과제에 맞게 설정되는 하나의 시뮬레이터), **비용**(고정된 내재 비용 + 학습하는 비평자), **행위자**(세계 모델로 비용을 최소화하는 행동열 계획), 단기 기억.

## 3. 이상적인 구조와 MK1의 빈칸

| 기능 | 뇌 / 이론 | MK1 지금 | 빈칸 |
|---|---|---|---|
| 지각 | 감각 피질 | 읽기 부품들 (글만) | 실제 글 위성들 연결 (v2) |
| 작업공간 | 전역 작업공간, 전전두엽 | 칠판 | 쓰기 예산, 방송, 과제 규칙 유지 |
| 라우팅·관문 | 시상 + 기저핵 | 사령탑 (회귀) | 관문 3개, 보상 예측 오차로 학습 |
| 확신 | 안와전두피질 | 0.5 기준 | 보정된 P(맞음), 기대 이득으로 결정 |
| 불확실성 조절 | 아세틸콜린, 노르에피네프린 | 세는 중재자 (아세틸콜린만) | **변화 감지** (노르에피네프린) |
| 일화 기억 | 해마 | 장기 기억 (글자 일치) | 뜻으로 찾기, 구조/내용 분리 |
| 응고 | 수면 재생 | 없음 | 재생 + 스키마 관문 |
| **세계 모델 (시뮬레이터)** | 소뇌 순방향 모델, LeCun 세계 모델 | **없음** | **가장 큰 빈칸.** "행동하기 전에 머릿속으로 해 보기" |
| **계획 (행위자)** | 전전두엽 + 기저핵, LeCun 행위자 | **없음** (답만 함) | 여러 단계 행동열을 세계 모델로 시험해서 고르기 |
| 비용·동기 | 도파민, LeCun 비용 | 문제 점수, 호기심(2단계) | 내재 동기(무엇을 배울지 스스로 고름) |
| 구성기 (메타 제어) | 전전두엽 계층 제어, LeCun 구성기 | 없음 (정책을 사람이 고름) | 과제를 보고 모드와 파라미터를 정함 |
| 배우는 법 배우기 | Lake 외 | 성장 (가설 공간을 사람이 정함) | 가설 공간 자체를 경험으로 넓힘 |

**MK1이 이미 가진 것 중 이론과 맞는 것**: 칠판(전역 작업공간), "주소는 구조로, 내용은 학습으로"(TEM의 구조/내용 분리와 같은 발상), 세는 중재자(아세틸콜린, 정밀도 가중), 실패율로 촉발되는 성장(지속적 예측 오차), 가설을 세워 시험하는 성장(9단계).

**가장 큰 빈칸 두 개**: 세계 모델과 계획. 이 프로젝트의 처음 정의에도 "생각 = 행동 전 시뮬레이션과 가설 검증"이 있었다. 지금 MK1은 답을 고를 뿐 시뮬레이션하지 않는다.

## 4. MK1 v3의 처리 순환 (한 문제 또는 한 행동마다)

```
1. 지각     위성들이 입력을 칠판 Claim으로 (conf 포함)           [감각 피질, 말하기 위성]
2. 회상     해마: 일화 기억 + 구조 지도에서 관련 Claim             [해마/내후각]
3. 경쟁     작업공간 쓰기 예산 안에서 Claim 경쟁 → 방송            [전역 작업공간]
4. 구성     구성기가 과제 규칙과 위성 파라미터를 정함               [전전두엽, LeCun 구성기]
5. 생각     후보 답/행동 제안 → 세계 모델로 결과 예측 →             [전전두엽 + 소뇌]
            사실 판단 위성으로 검증 → 답이 안 바뀔 때까지 되풀이     [TRM식 반복]
6. 결정     보정된 확신 × 이득 − 비용으로: 답 / 거절 / 더 묻기       [안와전두피질, 기저핵]
7. 표현     말하기 위성이 결론과 근거를 말로                         [언어 영역]
8. 배움     결과 → 보상 예측 오차(사령탑·비평자), 불확실성 신호      [도파민, 아세틸콜린, 노르에피네프린]
            (중재자), 일화 저장(해마), 쉬는 시간 재생 응고, 지속적
            예측 오차면 성장
```

## 5. 단계별 계획과 통과 기준

모든 단계의 비교 상대: Gemma 4 E4B 혼자(같은 메모리 예산), MK1 안의 LLM(Gemma 4 E2B) 혼자, 위성 하나씩 뺀 MK1. 외부 시험은 봉인 규칙을 따른다.

### 1단계: 실제 글 위에서의 판단 (기반)
- 만들 것: v2 칠판(쓰기 예산, 방송), 말하기 위성(parse/speak), 읽기·사실 판단·뜻 찾기 위성, 보정된 확신, 변화 감지 중재자.
- 시험: RGB(잡음, 거절, 반사실), 우리 v11 변형(세션 중간 신뢰도 변화).
- 통과: 거절과 반사실에서 Gemma E4B 혼자보다 높음(세션 단위 구간 > 0). 위성마다 ΔS > 0, 아니면 뺌.

### 2단계: 생각 (세계 모델 + 반복 추론)
- 만들 것: Claim 그래프 위의 TRM식 반복 추론기, 결과를 예측하는 작은 순방향 모델, 검증 루프.
- 시험: ProofWriter 깊이 5(학습은 깊이 ≤ 3, 깊이 5는 봉인), 여러 단계 질문.
- 통과: 깊이 5에서 Gemma E4B 혼자보다 높음. 깊이가 깊어질 때 떨어지는 폭이 더 작음.

### 3단계: 배움 (평생 학습)
- 만들 것: 빠른 저장소(일화) + 느린 저장소(작은 부품) + 재생 응고 + 스키마 관문 + 뜻으로 찾기.
- 시험: 시간 순서 흐름. 가중치를 다시 학습하지 않고 날마다 점수가 오르는지, 바꿔 말한 질문, 옛 졸업 시험 유지.
- 통과: 학습 곡선 기울기가 0보다 큼(구간). LLM + 간단한 메모장보다 높음. 옛 능력은 그대로.

### 4단계: 스스로 자람과 배우는 법 배우기 (AGI 시작점 판정)
- 만들 것: 지속적 예측 오차로 성장 촉발, 구성기(과제 규칙 선택), 경험으로 넓어지는 가설 공간.
- 시험: **처음 보는 종류의 과제가 이어서 들어오는 흐름**에서 기술 습득 효율(Chollet). 예시 몇 개 만에 몇 점까지 가는지. ARC-AGI 공개 평가셋 도전(학습은 공개 학습셋만).
- 통과 = **AGI 시작점**: 같은 메모리 예산의 단일 모델보다 새 과제 학습 곡선이 가파르고, 1–3단계 능력이 유지되고, 모든 과정이 노트북 한 대에서 돈다.

## 6. 정직한 메모

- 뇌 이론은 설계 가설이다. 우리 시험에서 반증되면 버린다.
- 1단계 시험 중 일부(RGB)는 영어·중국어다. 한국어 위성과 영어 위성 둘 다 필요할 수 있다.
- 세계 모델은 범위를 좁혀서 시작한다(글 위의 Claim 그래프에서 "이 행동/주장을 하면 무엇이 참이 되나" 예측). 물리 세계 시뮬레이터가 아니다.

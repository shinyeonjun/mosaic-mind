# 규칙 세계 v2: 경험으로 판단을 배우는 세계

작성일: 2026-10-06
상태: 생성기·신탁·코드 판단기·점수판·텍스트 파이프라인 구현 완료, N2·L2 대기
이전 단계: [규칙 세계 v1](world-v1-korean-rule-world.md)

## v1에서 넘어온 질문

v1에서는 "읽기는 학습 모델, 판단은 코드" 구조(P2, P2-nli)가 네 분할 모두에서 1.000을 받았다. 다만 판단 규칙은 사람이 코드로 써 주었다. "관리인 > 안내판 > 지나가던 사람"이라는 신뢰 순서를 시스템이 배운 게 아니다.

v2는 다음을 묻는다.

> **판단 규칙을 알려주지 않으면, 시스템이 경험에서 그 규칙을 배워 판단할 수 있는가? 그리고 그 배움은 어떤 구조에 맡기는 것이 가장 좋은가?**

## 한 번에 하나만 바꾼다

- **바뀌는 것**: 판단 규칙(누구를 얼마나 믿을지)을 숨긴다. 대신 문제마다 정답을 알려 주는 피드백을 준다.
- **그대로 두는 것**: 문장 표현은 v1 템플릿을 그대로 쓴다. 문, 열쇠, 공통 형식도 같다. 그래서 v1에서 학습한 언어 부품(P2-nli)을 그대로 다시 쓸 수 있다.
- 말의 다양성(대명사, 한 문장에 사실 두 개 등)은 별도 단계(v3)에서 바꾼다. 두 가지를 동시에 바꾸면 점수 변화의 원인을 나눌 수 없다.

## 세계

### 세션

세션 하나는 문제 40개가 이어지는 단위다. 한 세션 안에서는 다음이 유지된다.

- **말하는 사람 4명**: 이름은 세션마다 이름 풀에서 새로 뽑는다(예: 민수, 서연, 도윤, 하린). "관리인"처럼 역할을 암시하는 이름은 쓰지 않는다. 이름만 보고 믿을 만한 사람을 짐작할 수 없게 하기 위해서다.
- **사람마다 숨은 정확도 p**: {0.95, 0.75, 0.5, 0.2} 중에서 뽑는다. 한 세션의 4명이 모두 같은 값을 갖지는 않는다. 이 값은 에이전트에게 알려주지 않는다.
- 세션의 30%는 **변화 세션**이다. 21번째 문제부터 한 사람의 정확도가 크게 바뀐다(예: 0.95 → 0.2). 낡은 믿음을 고치는 능력을 본다.

### 문제 하나

- 질문한 문에는 숨은 진짜 열쇠가 있다. 사전 확률은 균등하다.
- 0–3명이 질문한 문에 대해 말한다. 다른 문에 대한 말과 잡담이 방해 문장으로 섞인다.
- 정확도 p인 사람이 하는 말은 다음과 같이 생성된다.
  - 긍정 문장: 확률 p로 진짜 열쇠를 말한다. 아니면 틀린 열쇠 2개 중 하나를 고르게 말한다.
  - 부정 문장: 확률 p로 틀린 열쇠 2개 중 하나를 "안 열린다"고 말한다. 아니면 진짜 열쇠를 "안 열린다"고 말한다.
  - 정정: 같은 사람이 먼저 아무 열쇠나 말했다가 정정한다. 판단에 쓰이는 것은 정정한 말뿐이다. 앞말은 무작위 소음이다.
- 에이전트는 열쇠 하나 또는 `모름`으로 답한다. 점수는 v1과 같다. 맞으면 +1, `모름`이면 0, 틀리면 −1이다.
- **피드백**: 답한 뒤에 그 문의 진짜 열쇠를 알려 준다. 에이전트는 이걸로 누가 맞았고 누가 틀렸는지 확인할 수 있다.

### 이 세계의 "이상적인 판단"은 수학적으로 정해져 있다

사람별 정확도를 안다면, 최선의 판단은 **베이즈 사후확률**로 계산된다. 각 문장이 진짜 열쇠에 대해 얼마나 증거가 되는지 곱해서 확률을 구하는 방식이다. 가장 높은 확률이 0.5를 넘으면 답하고, 아니면 `모름`이라고 하는 것이 기대 점수를 최대로 만든다. 이것이 정확도를 아는 **신탁(oracle)** 기준선 O2이고, 이 세계에서 가능한 점수의 상한이다. 어떤 문제는 원래 애매하기 때문에 O2도 만점은 아니다.

에이전트는 정확도를 모른다. 그래서 피드백으로 정확도를 **추정**해야 한다. 성능은 O2와의 차이로 잰다. 이것이 "공부"를 정량화한 값이다.

## 비교할 구조

| 이름 | 판단 방식 | 공부 방식 | 역할 |
|---|---|---|---|
| O2 | 베이즈, 진짜 정확도 사용 | 없음 (이미 앎) | 상한선 |
| B0-다수결 | 말한 사람 수가 가장 많은 열쇠 | 없음 | 공부 없는 기준선 |
| B1-동등신뢰 | 베이즈, 모두 같은 정확도로 가정 | 없음 | 공부 없는 기준선 |
| B2-경험신뢰 | 베이즈, 사람별 정확도를 피드백으로 추정 (Beta 사전분포 + 횟수 세기) | 코드로 된 학습 규칙 | **"판단 코드 + 경험 기억"** 구조 |
| B2-망각 | B2와 같고, 오래된 경험의 가중치를 줄임 | 코드 + 망각 | 변화 세션 대응 |
| N2 (다음 단계) | 신경망 판단기: 사건 기록과 경험을 받아 답을 냄 | 여러 세션으로 메타학습 | 학습된 판단 부품 |
| L2 (다음 단계) | LLM이 세션 전체 대화를 읽고 답 | LoRA | LLM 단독 비교군 |

B2는 뇌 비유로 하면 해마(누가 맞았는지 기억) + 전두엽(그 기억으로 판단)이다. 둘 다 코드이고, 기억의 내용만 경험으로 채워진다. N2는 이 판단을 신경망이 배우게 했을 때 B2를 넘거나 따라잡는지 본다.

## 지표

- **주 지표**: 세션 평균 보정 점수, O2와의 차이(regret)
- **학습 곡선**: 문제 1–10, 11–20, 21–30, 31–40 구간별 점수. 공부가 되면 뒤로 갈수록 O2에 가까워져야 한다.
- **변화 대응**: 변화 세션에서 바뀐 직후 10문제의 점수
- **보정**: 답한 문제의 정답률과 보류 비율
- 결과는 seed 6개, 세션 단위로 묶어서 평균과 신뢰구간을 낸다.

## 지름길 검사

- 진짜 열쇠는 문제마다 3종이 고르게 나온다.
- 이름과 정확도는 무관하다. 이름은 세션마다 새로 뽑고 정확도와 독립적으로 배정한다.
- 이름 풀은 훈련/검증/시험에서 겹치지 않는다. 특정 이름을 외워서 신뢰도를 맞히는 것을 막기 위해서다.
- v1 지름길 기준선(처음/마지막/가장 많이 나온 열쇠)도 기록한다. 다만 v2에서는 "가장 많이 나온 열쇠"가 다수결이라는 정당한 판단 전략과 겹친다. 그래서 기각 기준이 아니라 참고 기준선(B0)으로 다룬다.

## 에이전트 계약

```text
start_session(session_meta)       # 세션 시작: 말하는 사람 이름 목록
act(episode) -> answer            # 문제 하나에 답하기
feedback(episode, true_answer)    # 정답 확인 (공부할 기회)
```

언어 부품을 붙이는 조건에서는 에이전트가 문장만 받는다. 정답 구조 조건에서는 `gold_events`도 받는다. v1과 같은 방식이다.

## 구현 순서

1. 세션 생성기, O2, B0/B1/B2, 세션 점수판, 지름길 검사 (GPU 필요 없음)
2. v1의 P2-nli 언어 부품을 다시 써서 "읽기(학습) → 경험 기억 → 판단(B2)" 전체 파이프라인 구성
3. N2(신경망 판단기)와 L2(LLM 단독) 비교
4. 결과를 보고 v3(말의 다양성)로 넘어갈지 정한다.

## 1차 결과 (시험 세션 100개 × seed 6개, 평균 ± 표준편차)

| 판단기 | 전체 | 문제 1–10 | 문제 31–40 | 변화 직후 10문제 |
|---|---:|---:|---:|---:|
| O2 신탁 (정확도를 앎) | 0.443 ± 0.015 | 0.440 | 0.461 | 0.456 |
| B0 다수결 | 0.208 ± 0.019 | 0.209 | 0.208 | 0.226 |
| B1 동등신뢰 | 0.208 ± 0.019 | 0.210 | 0.207 | 0.226 |
| **B2 경험신뢰** | **0.374 ± 0.017** | 0.321 | **0.408** | 0.330 |
| B2 망각 (γ=0.9) | 0.372 ± 0.017 | 0.320 | 0.405 | **0.363** |

- **공부가 된다**: 피드백 없는 판단기(B0, B1)는 세션 내내 0.21 근처에 머문다. B2는 세션 초반 0.32에서 후반 0.41로 올라간다. 상한선(0.46)과의 차이가 줄어든다.
- **망각의 역할**: 전체 점수는 거의 같다. 하지만 사람의 정확도가 바뀐 직후에는 망각이 있는 쪽이 낫다(0.363 대 0.330). 다만 seed 간 편차(±0.06)가 커서 아직 확정할 수는 없다.
- **부품 재사용**: v1에서 학습한 NLI 언어 부품을 고치지 않고 꽂아서 문장을 직접 읽게 했다(`--text`). 결과는 정답 구조를 줄 때와 소수점 넷째 자리까지 같았다. 서로 다른 문장 224종을 모두 정확히 읽었다는 뜻이다. "읽기(학습된 부품) → 경험 기억 → 판단(코드)"의 전체 연결이 처음으로 작동했다.
- **한계**: B2의 학습 규칙(맞은 횟수 세기)도 사람이 썼다. 시스템이 바뀌는 건 기억의 내용뿐이다. 다음 단계 N2에서는 이 학습 규칙 자체를 신경망이 여러 세션을 거치며 배우게 하고(메타학습), B2를 넘는지 본다.

## 2차 결과: 이상적인 학습자(B3)와 신경망 판단기(N2)

수식 유도, 학습 곡선, 보정 곡선, 신뢰 추정 그래프는 [notebook/world2_learning_to_judge.ipynb](../notebook/world2_learning_to_judge.ipynb)에 있다.

- **B3**(`world2/bayes_learner.py`)는 이 세계의 사전분포(정확도 수준 4개)를 알지만 개인별 정확도는 모르는 베이즈 최적 학습자다. 맞은 횟수와 틀린 횟수가 충분통계량이다. 변화에 대응하는 hazard는 검증셋에서 h=0.01을 골랐다.
- **N2**(`world2/neural_judge.py`)는 파라미터 약 5천 개짜리 신경망이다. 사람마다 같은 가중치의 GRU로 기억을 두고, 열쇠 순서에 무관한 증거 머리를 쓴다. 학습은 교차엔트로피만 쓴다. 훈련 세션 3000개로 메타학습했고, seed당 CPU로 약 1분 걸렸다.

| 판단기 | 전체 (seed 6개) | 문제 31–40 | 변화 직후 10문제 | B3-h01 대비 (95% CI) |
|---|---:|---:|---:|---|
| O2 신탁 | 0.443 ± 0.015 | 0.461 | 0.456 | — |
| **B3-h01 이상적 학습자** | **0.380 ± 0.017** | 0.420 | 0.364 | 기준 |
| **N2 신경망 판단기** | **0.376 ± 0.016** | 0.416 | 0.355 | −0.004 [−0.008, −0.000] |
| B2 횟수 세기 | 0.374 ± 0.017 | 0.408 | 0.330 | −0.006 [−0.008, −0.003] |
| N2 기억 없음 | 0.207 ± 0.018 | 0.206 | 0.219 | −0.173 [−0.189, −0.158] |

- N2는 공식을 받지 않고도 이상적 학습자와의 차이를 0.004 이내로 좁혔다. 다만 신뢰구간이 0에 닿기 직전이어서, B3를 넘거나 같다고는 말할 수 없다. 사람이 쓴 학습 규칙(B2)보다는 약간 앞서고, 변화 직후 적응(0.355 대 0.330)이 특히 낫다.
- 로그 손실(seed 42): B3 0.774, N2 0.776, 기억 없는 N2 0.942. 보정 곡선에서 N2의 자신감과 실제 정답률은 거의 대각선 위에 있다.
- N2의 증거 머리를 베이즈 형태로 되돌려 구한 "암묵적 정확도"는 B3의 사후 평균 정확도와 문제마다 거의 겹친다(노트북 5번 그래프). N2가 배운 것은 근사적인 베이즈 학습 규칙이다.
- 기억을 끄면 공부가 사라져서 동등신뢰(B1) 수준으로 떨어진다. 공부는 기억 경로에서 나온다.
- **O2와 학습자 사이의 0.06–0.07 차이는 줄일 수 없는 비용이다.** 처음 보는 사람을 판단하려면 증거가 쌓여야 하기 때문이다. 따라서 이 세계에서 학습자 평가의 기준선은 O2가 아니라 B3다.

**해석**: 판단 부품을 신경망으로 바꿔도, 연결 구조(사람별 공유 기억 + 열쇠 대칭 증거 + 기대점수 최적 결정 규칙)를 잘 설계하면, 작은 망이 수학적 최적 학습에 도달한다. 구조에는 대칭성만 넣었고, 수치는 경험에서 배웠다.

## 3차 결과: 부분 피드백, 규모, 오설정

### 부분 피드백 ("맞았다/틀렸다"만, `모름`은 피드백 없음) — `world2/partial.py`

- **B4**: 정확도 수준 배정 4^4 = 256가지에 대한 정확한 결합 베이즈다. 생성 과정의 사전분포와 변화 규칙을 반영하고, 피드백이 없어도 말들이 서로 맞는지에서 배운다. 정답 피드백에서도 B3보다 약간 낫다.
- seed 6개 결과: 정답 피드백 대비 정보 손실은 0.024이고 유의했다. 탐색 휴리스틱의 효과는 +0.003으로 유의하지 않았다. N2-partial은 B4보다 0.003 낮았다(seed 4개 기준 유의). 횟수 세기(B2-partial)는 B4보다 0.009 낮았다.
- **해석**: 이 세계에서는 탐색의 가치가 작다. 피드백 없이도 말들의 일치 여부에서 정보를 얻기 때문이다.

### 규모: 정보원 수 S — `--speakers S`, `--sparse`

- 계산 시간(문제당): B4는 S=4일 때 0.03ms, S=8일 때 4.4ms, S=10일 때 97ms다. S≥12는 거부한다(4^S 상태). B5(ADF, 사람별 독립 근사)와 N2는 S와 거의 무관하게 0.1ms와 0.7ms다.
- S=8, 문제당 말하는 사람이 S에 비례할 때(seed 6개): B4 0.600, B5 0.598, N2-partial(4명 세계 학습) 0.596이다. 차이는 유의하지 않거나 매우 작다. 사람이 많아지면 다수결이 강해져서 문제가 쉬워진다.
- S=20, 문제당 말하는 사람 1.75명(드문 증거, seed 6개): B5 0.287, B2-partial 0.286, N2-partial(4명 세계 학습) 0.279(−0.008, 유의)다. 20명 세계에서 직접 학습시킨 N2도 seed 42에서 0.292로 같은 수준이었다.
- **해석**: N2는 재학습 없이 4명에서 20명으로 옮겨진다(공유 가중치). 하지만 생성 규칙을 아는 엔지니어는 확장 가능한 근사 코드(B5)를 쓸 수 있고, 그 코드는 N2와 같거나 낫고 더 싸다. **규모만으로는 학습이 코드를 이기지 않았다.**

### 오설정: 현실이 표준 규칙과 다를 때 — `world2/misspecified.py`, `--misspecified`

사람마다 숨은 유형이 있다. 표준, 긍정/부정 정확도가 따로, 서서히 변함(무작위 보행), 따라쟁이(지정된 사람의 말을 70% 확률로 반복) 중 하나다. 신탁 O2-M은 모든 유형을 안다. 피드백은 정답이다.

| 판단기 | 전체 (seed 6개) | 문제 31–40 | B4 대비 (95% CI) |
|---|---:|---:|---|
| O2-M 신탁 | 0.445 ± 0.018 | 0.444 | +0.117 |
| B3 / B4 / B5 (표준 규칙) | 0.328–0.331 | 0.352–0.354 | ≈ 0 |
| N2 (표준 세계에서 학습) | 0.331 ± 0.020 | 0.354 | +0.004 [+0.000, +0.007] |
| B3-informed (긍정/부정 분리 + 매 문제 hazard, 검증셋으로 h=0.02 선택) | 0.340 ± 0.021 | 0.370 | +0.012 [+0.007, +0.017] |
| **N2-mis (v2-M에서 학습)** | **0.343 ± 0.022** | 0.369 | **+0.016 [+0.010, +0.021]** |
| **N2-mis + 맥락 입력** | **0.344 ± 0.021** | 0.372 | **+0.017 [+0.011, +0.023]** |

- 표준 규칙으로 유도한 코드는 정확하든(B4) 근사하든(B5) 같은 수준에 막혔다.
- 실제 세계 데이터로 학습한 N2는 모든 코드보다 유의하게 높았다. 오설정 두 가지를 미리 반영한 코드(B3-informed)보다도 +0.005 [+0.000, +0.009] 높았다.
- 같은 N2 구조라도 표준 세계에서 학습하면 이득이 없다. 이득은 구조가 아니라 **실제 분포에서 배웠다는 것**에서 나온다.
- 맥락 입력(같은 주장을 한 다른 사람 수)의 추가 효과는 +0.001로 확인하지 못했다.
- 신탁과의 차이는 여전히 0.10이다. 학습된 판단기도 오설정의 일부만 잡아냈다.

**종합**: "규칙을 정확히 알면 코드(B4/B5)가 같거나 낫고 더 싸다. 규칙이 틀렸거나 모르면, 같은 데이터에서 배운 작은 신경망이 코드를 넘는다." 오케스트레이션에서 실제 부품의 오류 패턴은 미리 알 수 없다. 그래서 이것이 판단 부품을 학습 가능하게 둘 근거다.

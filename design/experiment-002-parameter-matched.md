# 실험 002 — 파라미터 수를 맞춘 비교

## 목적

실험 001에서 RIMs형 모델이 높은 점수를 냈다. 두 모델의 파라미터 수는 크게 달랐으므로, 이번에는 GRU를 두 크기로 둔다. 001 결과 파일과 체크포인트를 보존하도록 새 실험 ID와 저장 경로를 쓴다.

## 비교 조건

| 모델 | 구성 | 파라미터 수 | 맞추는 기준 |
|---|---|---:|---|
| `gru_state_matched` | GRU, hidden 256 | 206,084 | RIMs형과 상태 크기 256을 맞춤 |
| `gru_parameter_matched` | GRU, hidden 153 | 75,892 | RIMs형 파라미터 수와 거의 맞춤 |
| `rims` | 4 모듈 × 64, top-1 | 75,912 | 기준 구조 |

세 조건은 같은 에피소드, optimizer, 최대 epoch, 학습 seed를 쓴다. GRU 153은 상태 크기가 작고, GRU 256은 파라미터 수가 더 많으므로 두 GRU 비교를 함께 보고 용량 차이와 구조 차이를 구분한다. RIMs형 코어는 top-1 상태 갱신을 사용하지만 후보 업데이트를 모두 계산한다.

## 반복 방법과 지표

- 첫 실행은 seed 42. 반복 비교는 seed 43–47을 추가한다.
- 각 seed마다 학습·검증·시험 세트를 별도 생성한다. 세 모델은 해당 seed의 동일한 자료를 공유한다.
- 주 지표는 시험 정확도와 정정 에피소드 정확도다. 정보 누락 시 `ABSTAIN` 정확도와 학습 시간도 같이 본다.
- 여러 seed 결과에서 모델별 평균과 표준편차를 비교한다. seed 42 한 번이나 에피소드 1,024개만으로 우열을 확정하지 않는다.

## 해석 범위

이 실험은 구조화된 가상 관측의 기억·정정 과제다. 성공해도 한국어 문장 이해, 장기기억, Hugging Face 모델 오케스트레이션, 전체 인지 시스템의 성능을 입증하지 않는다. 해당 범위는 이후 별도의 실험으로 둔다.

# 직접 만들어야 할 것까지 산정한 분석 (2026-10-10)

질문: 아직 AGI를 만든 사람이 없으니, 남이 만든 방법을 가져다 쓰는 것으로는 안 되고 핵심 부품을 우리가 처음부터 만들어야 할 수도 있다. 그 경우까지 포함하면 무엇을 만들고, 얼마나 들고, 어디서 멈출지.

(용어 정리: 14절의 "라이브러리 학습"은 소프트웨어 라이브러리가 아니라, 풀린 프로그램에서 반복되는 조각을 모아 새 동작으로 쓰는 방법의 이름이다.)

## 1. 지금까지 빌린 것과 만든 것

| 빌린 것 (남이 학습한 부품) | 만든 것 (우리 설계와 학습) |
|---|---|
| Gemma 4 E2B/E4B (말하기), bge-large / e5-small (눈), mDeBERTa NLI, KLUE·SQuAD 독해 바탕 | 칠판과 하나의 순환, 보정기와 기대 점수 결정, 세는 중재자·변화 감지 중재자 |
| | 다단계 선택기·독해기(HotpotQA로 우리가 학습), 영어 읽기 위성(SQuAD로 이어 학습) |
| | 격자 생각 위성(기본 동작 약 90개, 손으로 만듦), 과제마다 자라는 부품, 맥락 추론 자라기 |

이긴 시험(새 과제 배우기, ARC, 스스로 자라기)의 핵심은 전부 **만든 쪽**이다. 빌린 부품은 지각과 말하기를 맡았다.

## 2. 세상에 아직 없는 것 (우리가 만들어야 하는 것)

| 능력 | 지금 세상의 상태 | MK1의 상태 |
|---|---|---|
| **새 개념 얻기** (예시 몇 개로 "속이 빈 물체", "경계까지 늘이기" 같은 개념을 새로 만들고 다시 쓰기) | 열린 문제. ARC-AGI-2 최고 수준도 낮다 | 없음. 손으로 만든 기본 동작 밖은 못 본다(ConceptARC 최소 과제 16개념 중 12개 표현 불가) |
| **배우는 법 배우기** (과제를 겪을수록 새 과제를 더 빨리 배움) | 메타학습 연구는 있지만 일반적으로 되는 시스템은 없다 | 라이브러리 학습 시도: 효과 없음(14절) |
| **검증기 없는 생각** (확인할 방법이 없는 추론) | 큰 LLM이 가장 잘함, 작은 모델은 약함 | MuSiQue에서 짐 |
| **스스로 무엇을 공부할지 정하기** (자기 교과과정) | 연구 단계 | 없음 |

## 3. 가장 가까운 시도들이 말하는 것

| 시도 | 결과 | 교훈 |
|---|---|---|
| DreamCoder (라이브러리 학습 + 신경 인식, 2021) | 좋은 기본 언어가 있는 영역에서 동작 | 기본 언어에 개념이 없으면 묶어도 안 생긴다. 우리가 14절에서 같은 벽을 확인했다 |

공통점: 잘 되는 쪽은 **(1) 스스로 표현을 배우는 신경망, (2) 직접 만든 대량의 합성 과제, (3) 시험 시점에 과제마다 짧게 학습(적응), (4) 반복해서 고치기**를 쓴다. 손으로 만든 동작 목록을 늘리는 쪽은 천장이 낮다.

## 4. 노트북에서의 비용 (추정, 불확실성 큼)

- TRM 원래 학습: 4×H100 약 48시간, 70만 스텝 이상(2차 출처, 원 논문으로 확인 필요) = 약 190 H100-시간.
- RTX 5070 Laptop은 H100의 대략 1/8–1/12 처리량으로 본다 → 같은 학습은 **약 1,500–2,300시간(2–3개월 연속)**. 그대로는 불가능.
- 메모리는 문제 아님: 7M 모델은 8GB에 충분하다. 막히는 것은 시간이다.
- 현실적 범위: 스텝·데이터를 1/10–1/20로 줄여 **밤샘 몇 번(합계 100–200시간)**. 성능은 TRM보다 훨씬 낮을 것이다.

## 5. 선택지

| | A. 물체 규칙 학습기 | B. 처음부터 학습하는 작은 개념 학습기 | **C. B + 정확한 검증기 (추천)** |
|---|---|---|---|
| 무엇 | 손으로 정한 물체 특징(크기, 색, 모양, 위치, 구멍, 방향, 개수) 위에서 규칙 찾기 | 우리가 만든 합성 과제로 작은 격자 신경망(수백만 파라미터)을 처음부터 학습 + 과제마다 시험 시점 적응 | B가 답을 제안하고, 지금의 탐색기처럼 예시에 다시 대 보고 맞는 것만 답 |
| 새 개념 얻기 | 아니오(특징을 사람이 정함) | 예(표현을 스스로 배움) | 예 |
| 배우는 법 배우기 | 거의 없음 | 메타학습으로 측정 가능 | 예, 그리고 틀린 답을 거름 |
| 엔지니어링 | 1–2주 | 생성기 2–3주 + 모델·학습 1–2주 | B + 1주 |
| GPU | 거의 0 | 100–200시간(밤샘 여러 번) | 같음 + 시험 시점 적응 |
| 위험 | 낮음, 천장도 낮음 | 높음 | 높음, 대신 틀린 답이 적음 |
| 우리 원리와 맞음 | 부분 | 부분 | **"검증기가 있을 때만 더 생각한다"와 정확히 맞음** |

## 6. 반드시 지킬 것 (시험 오염 방지)

- 합성 과제 생성기는 **ConceptARC 문제를 보고 만들지 않는다.** Chollet의 핵심 지식 사전(물체성, 기하·위상, 수 세기, 목표 지향)에서 출발한 일반 목록으로 만든다. ConceptARC corpus는 봉인 그대로. 개념 이름 16개와 최소 과제 16개는 이미 봤다는 사실을 기록한다.
- ARC-AGI-1 evaluation은 이미 열었다(평가로 쓰지 않음, 학습 데이터로 쓸지는 사전에 정하고 기록).

## 7. 단계와 멈춤 기준 (한 길로)

1. **생성기** (2–3주): 핵심 지식 사전에서 개념 가족 약 30개, 가족마다 무한히 뽑는 과제. 통과: 생성된 과제를 지금 탐색기가 풀 수 있는 비율이 가족마다 다양함(너무 쉽지도 어렵지도 않음).
2. **작은 개념 학습기** (1–2주 + GPU 밤샘): 가족 일부로 학습. 통과(배우는 법 배우기의 첫 증거): **학습에 안 쓴 개념 가족**에서, 메타학습한 모델이 같은 크기의 처음부터 모델보다 적은 예시로 더 정확히 적응. 실패하면 여기서 멈추고 A로 간다.
3. **검증기 결합** (1주): 제안 → 예시 재실행 확인. 통과: ARC-AGI-1 training(개발용)에서 지금 탐색기보다 많이 풀고, 답했을 때 맞는 비율 0.9 이상 유지.
4. **봉인 판정**: ConceptARC 480개, 한 번. 상대: 지금 탐색기(MK1 v2), Gemma E4B. 판정 기준은 열기 전에 커밋.

**전체 추정**: 엔지니어링 5–8주, GPU 수백 시간(밤샘). 실패 확률 높음. 2단계에서 첫 판정이 나오므로 3–5주 안에 계속할지 알 수 있다.

## 8. 정직한 전망

- 이 길이 되면 MK1에 "새 개념을 스스로 얻는 부품"이 생긴다. 그것은 지금까지의 어떤 결과보다 "작은 AGI의 시작점"에 가깝다.
- 하지만 세계 최고 팀들도 여기서 막혀 있다(ARC-AGI-2 최고 24%). 노트북 한 대에서 기대할 수 있는 것은 **작은 규모에서 원리를 증명하는 것**(배우지 않은 개념 가족으로의 빠른 적응)이지, 점수 경쟁이 아니다.
- 실패해도 남는 것: 우리만의 합성 과제 생성기(평가와 교과과정에 계속 씀), 처음부터 학습한 작은 격자 모델(생각 위성의 직관 부분).

## 10. 2단계 사전 등록: 작은 개념 학습기 (2026-10-11, 학습 전에 커밋)

**질문**: 다른 개념 가족들로 미리 학습한 작은 모델이, 처음 보는 개념 가족을 처음부터 학습하는 같은 크기 모델보다 적은 예시로 더 정확히 배우는가(배우는 법 배우기의 첫 증거).

**가족 나누기** (`src/cognitive_lab/concepts/split.py`, 시드 고정, 그룹별 층화):
- train 17: outline, crop, recolour_by_colour, recolour_largest, fill_holes, connect_pairs, mirror_complete, inside_frame, tile, scale_up, flip, sort_bars, count_to_bar, size_parity, gravity, move_until_obstacle, odd_one_out
- dev 4 (적응 방법 고르기만): keep_extreme, centre_dot, majority_colour, ray_until_obstacle
- **test 7 (판정 한 번)**: remove_noise, remove_border_touching, translate, rotate, recolour_by_size, extend_to_wall, keep_same_shape
- 시드로 흐름을 분리: 미리 학습 `train-i`, 적응 `adapt-<run>-i`, 평가 `eval-i`. test 가족 과제는 적응 방법을 얼리기 전에는 만들지도, 보지도 않는다.

**모델**: 격자 8장(예시 3쌍 + 시험 입력 + 시험 출력 자리)을 14×14로 채워 1568개 토큰으로 넣는 작은 트랜스포머(수백만 파라미터). 토큰 = 색(0–9 + 격자 밖) + 행 + 열 + 격자 자리. 시험 출력 자리 196칸을 한 번에 예측(격자 밖 칸이 출력 크기를 정함). 구조와 미리 학습 길이는 dev 가족으로만 정한다.

**두 조건** (같은 구조, 같은 적응 방법):
- 미리 학습: train 17가족 과제로 처음부터 학습 → 새 가족의 과제 N개로 적응.
- 처음부터: 무작위 초기화 → 같은 N개로 적응.

**측정**: test 가족마다 적응 과제 N개로 미세조정(적응 시드 3개), 새 평가 과제 200개의 시험 출력 정확 일치(격자 전체가 맞아야 정답). 문항마다 3개 시드 평균.

**판정 기준**:
- **주 가설**: N=32에서 (미리 학습 − 처음부터) 정확 일치 평균 ≥ **+0.10**, 그리고 가족별 층화 부트스트랩(평가 과제 단위, 10000회) 95% 구간 하한 > 0.
- 보조(보고만): N=8 차이, N=0(적응 없이 예시만 보고 맞히기, 미리 학습 모델만), 가족별 표.
- **실패하면 2단계에서 멈추고 A(물체 규칙 학습기)로 간다.** 결과는 좋든 나쁘든 그대로 기록.

**판정 전 기록 (dev만 사용, test 가족은 아직 생성 안 함)**:
- 미리 학습: train 17가족, 20000스텝(73분), 2.68M 파라미터. 학습 가족 새 과제를 예시만 보고 정확 일치 0.746.
- 적응 방법 고르기 (dev 4가족, N=32). 원칙: **상대(처음부터)가 가장 잘하는 방법**을 고른다.

| 적응 방법 | 처음부터 평균 | 미리 학습 − 처음부터 |
|---|---|---|
| 300스텝, lr 1e-4 (시드 3) | 0.027 | +0.268 |
| **1500스텝, lr 1e-4** (시드 1) | **0.205** | **+0.105** [+0.079, +0.132] |
| 1500스텝, lr 3e-4 (시드 1) | 0.195 | +0.084 |
| 3000스텝, lr 1e-4 (시드 1) | 0.209 | +0.098 |

- 300스텝에서는 처음부터 모델이 덜 학습돼 차이가 부풀었다. 1500에서 처음부터 쪽이 거의 다 올라왔고(3000과 같음) 시간이 절반이라 **1500스텝, lr 1e-4, 배치 16으로 얼린다.**
- dev에서 본 위험: majority_colour는 처음부터 쪽이 이김(0.805 vs 0.720). 차이는 "처음부터 쪽이 거의 0인 가족"에서 나온다. +0.10 기준에 가깝다.

| extend_to_wall | 0.000 | 0.080 | 0.000 | 0.453 | 0.008 |
| keep_same_shape | 0.000 | 0.035 | 0.000 | 0.035 | 0.010 |
| **평균** | 0.042 | **0.241** | 0.009 | **0.365** | 0.065 |

- **주 가설 통과**: N=32에서 미리 학습 − 처음부터 **+0.300** [+0.285, +0.315] (기준 +0.10, 하한 > 0).
- 보조: N=8 차이 +0.232 [+0.220, +0.244]. **미리 학습 모델이 예시 8개로 낸 정확도(0.241)가 처음부터 모델이 32개로 낸 것(0.065)보다 높다.** 적은 예시로 더 정확히 배운다는 질문에 그대로 "예".
- 가족 단위로 보면 7개 중 6개에서 미리 학습이 앞서고, rotate는 둘 다 0(동점). 부트스트랩은 평가 과제를 다시 뽑을 뿐 가족 7개 자체는 고정이라, "다른 가족으로도 일반화" 주장은 가족 수(6/6 비동점)만큼만 강하다.

**냉정하게 남는 것**:
- 예시만 보고 새 가족을 맞히는 능력(N=0)은 거의 없다(평균 0.042). 학습 가족에서는 예시만 보고 0.746을 맞히지만, **처음 보는 개념은 몇 개 과제로 짧게 학습해야** 얻는다. 지금 얻은 것은 "빨리 배우는 바탕"이지, 예시 3개만 보고 새 개념을 바로 만드는 능력은 아니다.
- recolour_by_size는 적응 뒤(0.208)가 적응 전(0.280)보다 낮다. 적응이 해칠 때가 있다.
- rotate는 아무도 못 배운다. 회전은 이 구조(칸 위치 임베딩, 한 번에 예측)에 어렵다.
- dev(+0.105)와 test(+0.300)의 차이는 가족 구성 때문이다(dev의 majority_colour는 처음부터 쪽이 이김). 가족에 따라 효과 크기가 크게 다르다.
- 이것은 우리가 만든 합성 가족 안의 결과다. ARC 같은 사람이 만든 과제로 옮겨지는지는 3단계에서 따로 본다(지금 모델은 14×14까지만 받는다. ARC는 30×30까지).

**결론**: 2단계 관문 통과. MK1에 처음으로 "배우는 법을 배운" 부품(처음부터 학습한 2.68M 격자 모델)이 생겼다. 다음은 3단계(검증기 결합, ARC-AGI-1 training으로 개발).

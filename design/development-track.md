# 발달 트랙: 한 시스템이 쉬운 것부터 배워 자라는가

작성일: 2026-10-06
상태: 설계, D1 착수

## 목표

처음부터 다 아는 모델을 만드는 대신, **하나의 시스템이 쉬운 단계부터 배우고, 배운 것을 바탕으로 다음 단계를 더 빨리 배우게** 한다. 지금까지는 세계마다 새 시스템을 처음부터 학습했다. 발달 트랙에서는 같은 시스템이 계속 이어서 배운다.

## "자랐다"의 정의 (세 가지를 모두 잰다)

1. **습득**: 이번 단계의 시험 점수가 기준에 도달한다.
2. **유지**: 앞 단계의 시험 점수가 떨어지지 않는다. 새 것을 배우면 예전 것을 잊는 현상(파국적 망각)을 잰다.
3. **전이 (핵심)**: 앞 단계를 거친 시스템이 이번 단계를 **처음부터 배우는 시스템보다 적은 경험으로** 같은 점수에 도달한다. 학습 곡선(점수 대 경험량)으로 비교한다.

3이 보이지 않으면 발달이 아니라 기술을 따로 쌓아 둔 것일 뿐이다.

## 단계

| 단계 | 배우는 것 | 세계 | 상태 |
|---|---|---|---|
| 0 | 문장을 사실로 알아듣기 | v1 | 언어 부품 학습됨 (P2-nli) |
| 1 | 기억하고 정정을 반영하기 | v1 | 판단은 코드 (S1) |
| 2 | 누구를 믿을지 경험으로 배우기 | v2 표준 | N2 |
| 3 | 규칙이 깔끔하지 않은 세상 | v2-M | N2-mis |
| 4 | 모르면 질문하기 | 실험 006–010 계승 | 미연결 |
| 5 | 행동 전에 미리 생각하기 | 미정 | 없음 |
| 6 | 다양한 한국어 | v3 | 없음 |

## 시스템이 계속 지니는 것

- **언어 부품**: 단계가 바뀌어도 이어서 쓰고, 필요하면 추가로 학습한다.
- **기억 저장소**: 세션 안의 경험(누가 맞았나)과 세션을 넘는 지식(어떤 종류의 정보원이 있나)을 분리한다.
- **판단 부품**: 앞 단계의 가중치에서 출발해 다음 단계를 배운다.
- **부품 목록**: 단계가 늘면서 부품이 추가된다. 어떤 부품을 쓸지는 지휘 부품이 정한다(단계 4 이후).

## D1: 깔끔한 세상을 배운 아이가 지저분한 세상을 더 빨리 배우는가

가장 작은 발달 실험이다. GPU 없이 바로 돌릴 수 있다.

- **자란 아이**: v2 표준 세계에서 학습한 N2(세션 3000개)에서 출발한다. v2-M 세션 k개로 이어서 학습한다.
- **갓난아기**: 같은 구조의 N2를 무작위 초기값에서 시작해 v2-M 세션 k개로 학습한다.
- k = 25, 50, 100, 300, 1000, 3000. seed 6개.
- 지표: v2-M 시험 점수(습득과 전이), 이어서 학습한 뒤의 v2 표준 시험 점수(유지).
- 판정: 작은 k에서 자란 아이가 갓난아기보다 유의하게 높으면 전이가 있다. 같은 점수에 도달하는 데 필요한 세션 수의 비율을 "발달 이득"으로 보고한다.
- 예상: 두 세계는 "누구를 믿을지 배운다"는 공통 구조를 공유한다. 그래서 작은 k에서 이득이 클 것이다. k가 커지면 차이가 사라질 것이다. 유지 쪽에서는 v2-M을 배운 뒤 표준 세계 점수가 조금 떨어질 수 있다.

## 이후

- D2: 단계 0–3을 한 시스템으로 이어서 거치기. 언어 부품과 판단 부품을 모두 이어간다.
- D3: 망각을 줄이는 방법 비교. 예전 단계 경험을 다시 보기(replay), 부품을 고정하고 새 부품 추가하기.
- D4: 단계 4(질문하기)를 붙이고, 앞 단계에서 배운 신뢰 추정이 질문 선택을 빠르게 하는지 본다.

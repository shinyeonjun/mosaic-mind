# MK1 vs 언어모델 하나 (2026-10-08~09)

목적: "부품 조합이 LLM 하나보다 낫다"는 이 프로젝트의 가설을 측정한다. 객관성 감사 규칙을 따른다(`design/audit-2026-10-08.md`). 상대는 노트북에 있는 LFM2.5-1.2B-Instruct다.

## J1. 학습 안 한 LFM vs MK1

### 우리 세계 3종 (같은 문제 600개씩, 같은 정보)

`python -m cognitive_lab.mk1.versus --system mk1|llm`

- LFM이 받는 정보: 안내판 문장, 기사 원문, 질문. 기사가 있는 세션에서는 지난 질문들의 정답과 "각 출처 기사에 정답이 들어 있었는지"도 받는다. 이건 MK1이 받는 피드백보다 깨끗한 정보다(LFM에 유리).
- LFM의 답 방식은 세 가지다. 확률 합 / 토큰당 평균 확률 / 직접 쓰기. 종류마다 **가장 좋은 방식**을 LFM 성적으로 쓴다. 이 문제들을 보고 고른 거라 LFM에 유리하다.

| 종류 | MK1 | LFM (가장 좋은 방식) | LFM 다른 방식 |
|---|---:|---:|---|
| 사슬 (생각: 더 긴 사슬, 모름) | **0.968** | 0.203 (확률 합) | 평균 확률 0.173, 직접 쓰기 0.165 |
| 거짓 출처 섞인 기사 (판단), 엄격 채점 | **0.125** | −0.625 (직접 쓰기) | — |
| 같은 기사, "정답 포함이면 맞음" 채점 | **0.155** | −0.378 | — |
| 기사로 여는 문 (조합) | **0.427** | −0.015 (직접 쓰기) | 확률 합 −0.053, 평균 확률 −0.197 |

- **사슬**: LFM은 세 방식 모두 거의 다 "모름"이다. 맞힌 0.20은 원래 정답이 모름인 문제들이다. 길이 편향을 없애도(평균 확률) 마찬가지라, 채점 방식 탓이 아니다.
- **기사**: 너그럽게 채점해도 LFM은 81%를 틀린 답으로 냈다. 거짓 기사를 가려내지 못하고, 모를 때도 답을 지어낸다.
- **공정성 한계**: MK1의 부품은 이 세계들로 학습했고, LFM은 학습하지 않았다. 그래서 이 표는 "학습한 전문가 조합 > 학습 안 한 범용 모델"까지만 말해 준다. 공정한 비교는 J2(같은 데이터로 LFM 학습)에서 한다.
- 이 실행의 사슬·기사 결과는 메모리 부족으로 멈추기 전에 나온 숫자다. 기사로 여는 문은 사용자가 다시 돌렸다(`artifacts/results/mk1-versus_llm.json`에는 마지막 실행만 남아 있다).

### 외부 시험: KorQuAD 1.0 dev (한국어 읽기, 한 번만 봄)

`python -m cognitive_lab.mk1.korquad --system mk1|llm` → `artifacts/results/exam-korquad1_*.json`

규칙: KorQuAD로는 아무것도 학습하거나 조정하지 않았다. 시험지는 한 번만 열었다. 오염 검사에서는 5,774문제 중 7문제(0.1%)만 읽기 전문가가 학습 때 본 지문이었다. 글자가 조금 다른 비슷한 지문까지는 검사하지 못했다.

| | 정확 일치 (EM) | 글자 F1 | 우리 기준 맞음 | 속도 |
|---|---:|---:|---:|---:|
| **MK1 읽기 전문가** (KLUE로 학습, 0.28B, fp32) | **65.8** | **84.8** | **80.7** | 초당 30.9문제 |
| LFM 1.2B (학습 없음) | 52.3 | 70.4 | 61.6 | 초당 8.1문제 |

- 처음 보는 지문(5,767문제)만 봐도 같다(MK1 65.8 / 84.8, LFM 52.3 / 70.4).
- 채점은 공식 스크립트를 따라 다시 구현한 것이다(소문자, 문장부호와 띄어쓰기 제거, 글자 단위 F1). 공식 스크립트와 소수점이 다를 수 있다.
- **공정성 한계**: MK1 읽기 전문가는 KorQuAD로 학습하지 않았지만, **같은 종류의 과제**(KLUE 한국어 기사 질문 1만 4천 개)로 학습했다. LFM은 이 과제로 학습하지 않았다. 그래서 이것도 "과제로 학습한 0.28B > 학습 안 한 1.2B"다. 다른 데이터셋(KorQuAD)으로 넘어가도 학습 효과가 유지된다는 건 보여 준다.

## J2. 같은 데이터로 학습한 LFM vs MK1 (2026-10-09)

LFM도 **MK1 부품들이 배운 데이터**로 LoRA 학습했다(학습 파라미터 555만 개, 본체는 얼림). 시험 문제는 학습에 쓰지 않았고, 모델 고르기는 검증셋으로만 했다.

### 읽기: KLUE 1만 3,989문제로 학습 → KorQuAD 1.0 dev

`python -m cognitive_lab.mk1.versus_klue` (77분, GPU 2.8GB, KLUE 검증 0.37 → 0.58) → `python -m cognitive_lab.mk1.korquad --system llm --adapter ...`

| | 정확 일치 | 글자 F1 | 모름 비율 | 크기 / 속도 |
|---|---:|---:|---:|---|
| MK1 읽기 전문가 (KLUE 학습) | **65.8** | **84.8** | 0% | 0.28B / 초당 31문제 |
| LFM 학습 없음 | 52.3 | 70.4 | 0% | 1.2B / 초당 8문제 |
| LFM KLUE로 학습 | 48.9 | 57.6 | 30% | 1.2B / 초당 7문제 |
| LFM KLUE로 학습, "모름" 금지 | 48.9 | 60.1 | 0% | |

- 학습한 LFM은 KLUE의 "답 없음"(31%)을 배워서, 답이 다 있는 KorQuAD에서 **30%를 "모름"**이라고 했다. "모름" 토큰을 막으면 "모르름", "모르는", "모르지 않음" 같은 변형을 써서 그 문제들에서 EM 0, F1 8.6이다. 같은 문제에서 MK1 읽기 전문가는 EM 60.2, F1 80.9다.
- **LFM이 답한 같은 4,013문제만** 보면 거의 비긴다. LFM이 EM 70.4 / F1 82.7, MK1 부품이 68.3 / 86.5다. 다만 이 문제들은 LFM이 고른(아마 쉬운) 문제다.
- **결론**: J1의 큰 차이(F1 84.8 vs 70.4)는 대부분 "학습했냐 안 했냐"였다. 같은 데이터로 학습하면, 답하는 문제에서는 비슷하다. 하지만 **처음 보는 데이터셋으로 넘어갈 때** 0.28B 전문가가 더 안정적이고(모름 남발 없음), 크기는 4분의 1, 속도는 4배다.

### 우리 세계 3종: 같은 학습 세계 4,000문제로 학습

`python -m cognitive_lab.mk1.versus_train` (48분, GPU 4.0GB, 검증 −0.88 → −0.64) → `python -m cognitive_lab.mk1.versus --system llm --adapter ...`

| 종류 | MK1 (맞음 / 틀림) | LFM 학습 없음 | **LFM 같은 데이터로 학습** (맞음 / 틀림) |
|---|---:|---:|---:|
| 사슬 | **0.968** (0.97 / 0.00) | 0.203 | −0.048 (0.45 / 0.50) |
| 거짓 출처 기사 | **0.125** (0.38 / 0.25) | −0.625 | −0.015 (0.35 / 0.36) |
| 기사로 여는 문 | **0.427** (0.54 / 0.11) | −0.015 | −0.033 (0.48 / 0.51) |

- 학습하니 LFM이 **맞히는 비율은 크게 올랐다**(사슬 0.20 → 0.45, 기사로 여는 문 0.01 → 0.48). 하지만 **모를 때도 답해서** 틀림이 절반이다. 그래서 순점수는 0 아래다.
- MK1은 맞히는 비율도 높고(사슬 0.97), 모를 때 멈춰서 틀림이 적다(0.00 / 0.25 / 0.11). **차이의 핵심은 "언제 답하지 않을지 아는 것"**이다. 사슬에서는 추론 자체도 차이가 크다(맞음 0.97 vs 0.45).
- **공정성 한계**:
  - 학습량이 같지 않다. LFM은 노트북 시간 때문에 4,000문제, 1에포크만 학습했다. MK1 부품들은 원래 더 많이 봤다. 특히 기사 신뢰 부품은 2,000세션(8만 문제)이다.
  - LFM의 정답 기준은 "주어진 정보로 알 수 있으면 답, 아니면 모름"이다. 그래서 모름을 배울 기회는 있었다(검증에서 여전히 음수).
  - 사슬은 학습량 차이가 크지 않은데도(MK1 생각 부품도 수천 문제로 학습) 차이가 크다. 그래서 학습량만으로 설명되지는 않는다.

### J2 종합

- **읽기 하나**: 같은 데이터면 비슷하다. 전문가가 작고 빠르고, 처음 보는 데이터셋에서 안정적이다.
- **조합이 필요한 문제**: 같은 데이터로 학습해도 단일 LLM(1.2B)보다 MK1이 크게 낫다. 특히 모르면 멈추기와 여러 단계 추론에서 그렇다. 다만 우리가 만든 세계라는 한계가 남는다. 외부 시험에서 조합을 보이는 건 `design/agi-blueprint-2026-10-09.md`의 1–2단계 몫이다.

# 방향 선언 (2026-10-09): 골동품을 주워 엮어서 AGI의 시작점을 만든다

## 왜

LLM 하나에 다 시키는 건 뇌 하나만 키우는 것이다(사용자: "원피스 베가펑크처럼 뇌만 키우는 것 같다"). 우리는 이미 잘 만들어진 작은 특화 모델들(골동품)을 주워 와서 역할별 위성으로 두고, **엮는 층**으로 지능을 만든다. 목표는 노트북 한 대의 메모리 예산 안에서, 같은 예산의 단일 모델(예: Gemma 4 E4B)보다 낫고 AGI 특성을 보여 주는 "작은 AGI의 시작점"이다.

## 원칙

1. **역할마다 전문가 하나.** 큰 사전학습 모델은 얼려서 빌려 쓰고(비트는 최대한 낮게), 우리가 학습하는 건 작은 연결과 판단 부품이다. 몸집은 막히는 곳부터 조금씩 키운다.
2. **LLM은 언어모델답게, 말하기 담당만 한다.** 들어온 말을 칠판 형식으로 옮기고, 결론을 사람 말로 만든다. 추론, 판단(누구를 믿을지), 기억은 LLM에게 시키지 않는다. 그건 다른 위성의 몫이다.
3. **똑똑함은 엮는 층에서 나와야 한다.** 칠판, 사령탑(누구를 부를지), 신뢰·중재(누구를 믿을지), 기억(무엇을 쌓을지), 성장(언제 새 능력을 키울지).
4. **냉정한 판정.** 외부 시험은 봉인하고 한 번만 연다(`design/audit-2026-10-08.md`의 시험 규칙). 매번 세 가지와 비교한다.
   - 같은 예산의 최강 단일 모델
   - MK1 안의 LLM 혼자
   - 위성을 하나씩 뺀 MK1
   엮는 층이 더하는 몫이 0에 가까우면 방향을 다시 본다.

## 위성 배치

| 위성 | 역할 | 골동품 | 상태 |
|---|---|---|---|
| 말하기 | 말 → 칠판 형식, 결론 → 말 | Gemma 4 E2B (Google QAT 4비트 GGUF, llama.cpp) | 받음 |
| 읽기 | 글에서 답 찾기 | mDeBERTa QA (KLUE로 학습) | 있음 |
| 사실 판단 | 문장이 주장을 뒷받침하는지 | mDeBERTa NLI | 있음 |
| 뜻 찾기 | 비슷한 뜻, 기억 검색 | multilingual-e5-small | 있음 |
| 이름 찾기 | 사람·장소·날짜 | GLiNER | 있음 |
| 생각 | 여러 단계 추론, 퍼즐 | TRM식 작은 순환 추론기 (우리가 학습) | 만들 것 |
| 신뢰·중재 | 누구 말을 믿을지 | 신뢰 부품, 세는 중재자 | 있음 (만든 세계) |
| 기억 | 확인된 것을 쌓기 | 장기 기억 | 있음 |
| 사령탑 | 누구를 부를지 | 사령탑 | 있음 (일반화 필요) |
| 성장 | 막히면 새 능력 | 가지 키우기 (8–9단계) | MK1에 붙일 것 |
| 계산·코드 | — | 나중에 | — |

## AGI 시작점 판정 기준

외부 시험에서, 같은 예산의 단일 모델보다 낫게:
1. 모르면 멈춘다 (답 없는 질문 거절)
2. 누구를 믿을지 판단한다 (틀린 문서, 거짓 출처)
3. 배운 것보다 깊게 생각한다 (ProofWriter 깊이 5, ARC-AGI)
4. 겪으면서 자란다 (다시 학습 없이 시간이 갈수록 점수 상승)
5. 막히면 스스로 새 능력을 키운다

## 다음 순서

1. J2 마무리(공정 비교)와 기록
2. 말하기 위성 연결: llama.cpp로 Gemma 4 E2B를 띄우고, 말 → 칠판 형식, 결론 → 말
3. 실제 글에서 도는 위성들: 이름 찾기, 뜻 찾기, 사실 판단을 칠판에 올리기
4. 생각 위성: TRM식 추론기 (ProofWriter 학습셋, 깊이 5는 봉인)
5. AGI 성적표 1차: RGB, ProofWriter, 세 가지 비교

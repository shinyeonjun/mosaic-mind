# 통합 시스템 v1: 읽기 + 기억 + 판단

작성일: 2026-10-07
상태: 설계, 구현 착수
관련: [공통 형식 학습](interface-learning-v1.md), [규칙 세계 v2](world-v2-learning-to-judge.md), [연구 정리](research-log-2026-10-06.md)

## 목표

지금까지 부품을 따로따로 확인했다.

- **읽기**: 규칙 세계 v1에서 순서대로 키운 언어 부품(mDeBERTa-NLI, 대상 고정 메시지)
- **판단**: 출처 구조 판단기. 신뢰 순서를 *구조로* 받는다.
- **기억과 공부**: 규칙 세계 v2의 N2. 누구를 믿을지 *경험으로* 배우지만, 입력은 사람이 설계한 사실 형식(문, 열쇠, 긍정/부정)이다.

이번에는 이 셋을 한 시스템으로 묶는다. 사람이 설계한 사실 형식은 쓰지 않는다. 신뢰 순서도 주지 않는다.

> **v1에서 키운 읽기 부품을 재학습 없이 v2 세계로 옮기고, 그 위에서 기억과 판단을 경험으로 배우게 하면, 사람이 설계한 형식과 코드로 만든 최적 학습자에 얼마나 다가가는가?**

## 세계

규칙 세계 v2를 그대로 쓴다. 세션 하나는 문제 40개이고, 말하는 사람은 4명이다. 사람마다 숨은 정확도가 있고, 문제마다 정답 피드백을 준다. 문장은 v1 템플릿이므로 v1 읽기 부품이 읽을 수 있는 말투다. 비교는 표준 세계와 오설정 세계(v2-M) 둘 다에서 한다.

## 시스템 I1의 구조

```
문장마다, 열쇠 k마다 → 읽기 부품(고정) → 메시지 m[u,k] (4차원)
                                              │
사람 s마다, 열쇠 k마다: 같은 GRU가 s의 문장만 순서대로 읽음 → h[s,k]
     (정정은 같은 사람의 나중 말이 앞말을 덮는 것으로 배움)
                                              │
기억 부품: 사람마다 기억 벡터 mem[s] (모든 사람이 같은 가중치)
     피드백 뒤 갱신 입력: [말했는지, h[s, 정답 열쇠], 나머지 열쇠의 h 평균]
                                              │
판단: c[s,k] = f(h[s,k], mean_k h[s,·], mem[s]),  logit_k = Σ_s c[s,k]
     답할지 말지: 최대 확률 > 0.5이면 답하고, 아니면 모름 (기대 점수 최적, v2와 같음)
```

- **대칭성(틀)**: 사람 순서와 이름에 무관하다(공유 가중치, 합). 열쇠 이름에도 무관하다(같은 f, 열쇠 사이 평균).
- **신뢰 순서를 주지 않는다.** v1 출처 구조 판단기의 "신뢰 순서대로 합치기"를 기억 부품이 배운 신뢰로 대신한다.
- **학습**: v2 훈련 세션으로 메타학습한다. 손실은 정답 열쇠에 대한 교차엔트로피다. 읽기 부품은 고정하므로(2단계와 같음), 모든 (문장, 질문한 문, 열쇠) 메시지를 fp32로 한 번만 계산해 두고 쓴다. 함께 다듬기(3단계)는 이후 실험이다.

## 비교 대상 (모두 같은 v2 시험 세션, 문장 입력)

| 이름 | 읽기 | 판단·기억 | 사람이 설계한 것 |
|---|---|---|---|
| B3 / B4 (정답 구조) | 정답 사실 | 베이즈 최적 코드 | 사실 형식, 생성 규칙 |
| P2-nli + B3 | NLI 분류기 → 설계 형식 | 베이즈 코드 | 사실 형식, 생성 규칙 |
| P2-nli + N2 | NLI 분류기 → 설계 형식 | 학습(N2) | 사실 형식 |
| **I1** | 학습된 메시지 (v1에서 옮김) | 학습(I1) | 없음 (틀만) |

## 지표

- v2 점수(세션 평균 보정 점수)와 최적 학습자(B3)와의 차이
- 학습 곡선(문제 1–10, 31–40)
- 오설정 세계에서 코드 대비 이득
- seed 4개 이상, 짝 비교, 95% 신뢰구간

## 결과 (2026-10-07)

v1 읽기 부품은 `world-v1_reader-anchored-learned-sourcefold-staged-tuned_composition_seed-42.pt`이고, 고정한 채 메시지 2,016개를 미리 계산했다. v2 데이터(표준 + 오설정) 문장 246,383개가 모두 계산 범위 안에 있었다. 기억·판단 부품은 파라미터 약 1.7만 개이고, 세션 3,000개로 학습했다. 학습 중 검증 점수와 점수판 재채점이 일치했다(0.2637 = 0.2637, 시험 학습). 모든 비교 대상은 문장 입력 조건(`--text`)으로 채점했다.

| 시스템 | 표준 s42 | 오설정 s42 | 오설정 s43 |
|---|---:|---:|---:|
| 신탁 (모든 것을 앎) | 0.419 | 0.460 | 0.413 |
| B3 / B4: 설계 형식 + 베이즈 코드 | 0.351 (B3) | 0.345 (B4) | 0.293 (B4) |
| N2 / N2-mis: 설계 형식 + 학습 판단기 | 0.350 | 0.353 | 0.304 |
| **I1: 학습 메시지 + 학습 기억·판단** | **0.351** | **0.3545** | **0.302** |

- **표준 세계**: I1이 베이즈 최적 코드와 같은 점수다. v1 읽기 부품이 재학습 없이 v2로 옮겨졌다.
- **오설정 세계**: I1 ≈ N2-mis(+0.0015, −0.0023)이고, 코드보다 두 seed 모두 약 +0.009 높다.
- **해석**: 이 세계들에서는 설계된 사실 형식이 정보를 잃지 않는다. 그래서 학습된 메시지는 *같은* 결과를 냈고, *더 나은* 결과는 내지 못했다. 학습된 형식의 이점은 설계 형식이 버리는 정보가 있을 때만 나타날 수 있다. 이것이 다음 실험의 근거다.

## 미리 적어 두는 예상과 반증

- 표준 세계: I1이 P2-nli + N2에 근접한다(차이 0.02 이내). 근접하지 못하면, 학습된 메시지가 "누가 맞았는지"를 판단할 정보를 충분히 담지 못한 것이다.
- 읽기 부품 이전: v1에서 키운 읽기 부품이 v2 문장을 재학습 없이 읽는다. 실패하면 3단계(함께 다듬기)를 v2에서 다시 한다.
- 오설정 세계: I1이 설계 형식 + 베이즈 코드보다 높다. 설계 형식도 생성 규칙 가정도 없기 때문이다.

# 규칙 세계 v3: 이어진 단서 (사다리 3단계 "생각하기")

작성일: 2026-10-08

## 질문

한 번 읽어서는 못 풀고 단서를 여러 번 이어야 풀리는 문제에서, 시스템이 **스스로 생각 횟수를 정하고**, 학습 때 본 것보다 **긴 고리를 더 오래 생각해서** 푸는가?

## 세계 (`world3/chains.py`)

- 문 10개, 열쇠 3개. 질문한 문까지 "같은 열쇠" 고리가 L개 이어지고, 고리 끝 문(닻)에 사실 "닻은 K 열쇠" 하나가 있다.
- 방해 문 2–3개(작은 고리 1–2개, 각자 사실이 있다. 열쇠는 독립이라 언급된 열쇠로 찍는 지름길이 없다).
- 문장 순서는 섞는다. 20%는 고리 하나를 끊어서 답이 "모름"이다.
- 학습·검증: L = 1–3. **시험: L = 1–6 (4–6은 처음 본다).**
- 풀이기(union-find)와 정답이 2만 3천 문제에서 모두 일치한다.
- 점수: 맞으면 +1(맞는 "모름" 포함), 답이 있는데 "모름"이면 0, 틀리면 −1.

## 읽기 (`world3/features.py`)

- v1 읽기 부품 본체를 얼린다. (문장 750개 × 가설 75개) 특징을 fp32로 캐시한다. 가설은 "문은 열쇠로 열린다"(30개)와 "두 문은 같은 열쇠"(45개, 처음 보는 형태)다.
- 선형 탐침 (평가에 쓴 문 쌍은 학습에 안 씀): 사실 재현율 1.000 / 특이도 1.000, "같은 열쇠" 재현율 1.000 / 특이도 0.998.

## 생각 부품 (`world3/thinker.py`)

- (문, 열쇠)마다 상태 하나를 둔다. 모든 문과 열쇠에 같은 가중치를 쓴다.
- 한 단계에 연결된 문의 상태를 받아 GRU로 갱신하고, 처음 읽은 내용(z0)을 매번 다시 넣는다. 정보는 한 단계에 고리 하나씩 이동한다.
- 매 단계 "멈출까"를 학습한다. 입력은 질문 문의 상태, 확률, 이번 단계 변화량이다.
- 손실 = PonderNet(멈춤 분포로 가중한 CE + 생각 비용 0.01 × 기대 단계) + 모든 단계 CE 평균.
- 학습 때 최대 8단계, 시험 때 최대 12단계. 학습 파라미터는 연결 머리 2개 + 생각·멈춤 부품이다.

## 개발 과정 (검증 세트 L = 1–3만 봄, 시험은 안 봄)

1. 기본 PonderNet: 검증 1.0이고 생각 횟수 = L이지만, 억지로 8단계를 생각시키면 L=1이 0.57로 무너진다. 멈춘 뒤 단계는 학습 신호가 없기 때문이다.
2. 모든 단계 CE를 추가했더니 12단계까지 억지로 생각시켜도 검증 1.0을 유지했다.
3. 모델 선택: 검증 점수 → 마지막 단계 안정성 → 적은 생각 횟수 순.

## 미리 적어 두는 판정 (seed 42–44, `--test`)

- **졸업**:
  - (a) 처음 보는 L = 4–6에서 스스로 멈추는 점수의 seed 평균이 0.8 이상이고,
  - (b) 모든 seed에서 "3단계에서 억지로 멈춤"보다 +0.3 이상 높으며,
  - (c) 답이 있는 문제의 평균 생각 횟수가 L = 1..6에서 증가하고,
  - (d) L = 1–3 점수가 0.95 이상이다.
- **부분 성공**: (d)는 만족하고 (a)만 미달.
- **실패**: 긴 고리에서 3단계 멈춤과 차이가 없다.


## 1차 시험 무효 (2026-10-08)

seed 42–44로 시험했고, 결과는 L=1–3 1.00, L=4–6 0.17–0.88로 미달이었다. 진단하다가 **세계의 지름길**을 발견해서 이 결과는 무효로 처리한다(`artifacts/results/archive/`, 체크포인트에는 `.invalid-keyfreq`를 붙였다).
- 지름길 1: 방해 문의 열쇠를 독립으로 뽑았기 때문에 "가장 많이 나온 열쇠"가 찍기 이상으로 맞았다. 수정: 사실 3개가 열쇠 3개를 한 번씩만 말한다.
- 지름길 2: "연결이 있는 사실 문"의 열쇠가 정답 쪽에 치우쳤다. 수정: 방해 고리도 항상 2–3개 문(사실 + 연결)으로 만들고, 문을 12개로 늘렸다.
- 남은 전역 지름길: "가장 긴 고리의 사실"이 학습 0.59 / 시험 0.80 맞힌다. 0/1 연결은 다른 고리와 정보를 주고받을 수 없어서 이 지름길을 쓸 수 없다. 이를 **정보 도착 전(L번째 생각 전) 정답 확률이 약 0.33인지**로 매번 확인한다.
- 버그: 문장이 최대 12개인데 코드는 10개까지만 받았다. 수정했고, 넘치면 오류가 나게 했다.

## 개발 기록 (긴 고리 개발 세트, 설계 결정에만 사용)

| 시도 | 연결 | 전달 (억지로 12번 생각, L=6) | 스스로 멈춤 |
|---|---|---|---|

| 최대로 모으기 | 모든 쌍 1.0 (완전 그래프) | 다른 단서로 풂 | 실패 |

| + 0/1 연결, 멈춤 입력 제한 | **진짜 1.0 / 나머지 0.0** | 4칸까지 | L=4는 정확히 4번 |
| + 처음엔 모든 연결을 켜고 가지치기 (12개 문) | **진짜 1.0 / 나머지 0.0** | **L=4/5/6 모두 L번째에 1.0** | "3번이면 멈춤" |

**지금까지의 결론**
- 연결 찾기와 전달(생각하는 방법)은 학습 범위(3칸)를 넘어 6칸까지 일반화된다.
- **언제 멈출지는 아직 학습 범위를 못 벗어난다.** 학습에서 통하는 규칙("3번", "확신하면", "변화가 작으면")이 긴 고리에서는 너무 일찍 멈춘다.

## 최종 설계 (2026-10-08, 사용자 결정: 멈춤은 고정 규칙)

- **멈춤 규칙(틀)**: 모든 문의 답(확률) 변화가 **2번 연속 0.01 미만이면** 멈춘다. 긴 고리에서는 칸 사이에 한 단계씩 변화가 작아지는 구간이 있어서(개발 세트), 1번이 아니라 2번 연속으로 본다. 시험 때 최대 생각 횟수는 16번이다.
- **학습 순서** (`scripts/world3_grow.sh SEED --test`):
  1. 연결과 전달을 학습한다. 처음엔 모든 연결을 켜 두고, 연결 비용 0.1로 가지치기한다. 10 epoch.
  2. 연결을 얼리고 모든 문의 답도 채점한다(정답은 풀이기에서). 30 epoch. 모델은 검증 세트(L ≤ 3)로 고른다.
- 학습된 멈춤 머리도 계속 학습하고, 비교용으로 보고한다.
- 개발 세트(seed 0)에서 L = 4/5/6: 점수 1.0, 생각 6.0 / 8.0 / 10.5번.

## 최종 판정 (미리 적음, 처음 보는 seed 45–47)

- (a) L = 4–6 스스로 멈춤 점수의 seed 평균이 0.8 이상
- (b) 모든 seed에서 L = 4–6 점수가 "3번째 생각에서 억지로 멈춤"보다 +0.3 이상 높음
- (c) 답이 있는 문제의 평균 생각 횟수가 L = 1..6에서 증가
- (d) L = 1–3 점수 0.95 이상
- (e) 지름길 감사: 정보가 도착하기 전(L번째 생각 전) 정답 확률 평균이 0.36 이하 (L ≥ 2)
- 모두 만족하면 졸업. (d)는 되고 (a)가 미달이면 부분 성공.

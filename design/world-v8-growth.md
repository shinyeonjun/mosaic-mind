# 규칙 세계 v8: 스스로 성장 결정하기

작성일: 2026-10-08

## 질문

지금까지는 사람이 "새 부품이 필요하다"를 정했다. 이번에는 시스템이 다음을 스스로 하는가?
1. **알아채기**: 처음 보는 종류의 문제가 나타났고, 지금 부품으로는 못 푼다는 것을 알아챈다.
2. **결정하기**: 필요할 때만 새 부품을 키운다. 처음 보는 것이라도 지금 부품으로 풀리면 키우지 않는다.
3. **이어 붙이기**: 키운 뒤에도 옛 능력이 그대로다.

## 세계와 사전 측정 (`world8/chains.py`, `world8/language.py`)

v3 고리 문제에서 연결 문장이 세 가지 종류로 나온다.

| 종류 | 예 | 3단계 생각 루프 점수 (seed 45 / 46 / 47) | 올바른 행동 |
|---|---|---|---|
| 기존 표현 (same) | "빨간 문과 파란 문은 열쇠가 같아." | 1.00 / 1.00 / 1.00 | — |
| **새 말투** (same-new) | "빨간 문과 파란 문은 열쇠가 매한가지야." | **1.00 / 0.995 / 1.00** | 키우지 않기 |
| **다음 차례** (next) | "파란 문 열쇠는 빨간 문 열쇠의 다음 차례야." (해 → 달 → 별 → 해) | **0.20 / 0.17 / −0.16** | 키우기 |

- 새 말투는 읽기 부품이 일반화해서 그대로 푼다. 다음 차례는 못 풀고, seed 47은 확신하면서 틀린다(−0.16). 생각 루프는 연결을 따라 열쇠를 **그대로** 옮기도록 생겼기 때문이다.
- 기존 연결 머리는 다음 차례 문장의 39%를 "같음"으로 착각한다.

## 새 부품: 생각 루프에 덧붙이는 "다음 차례" 가지 (`world8/branch.py`)

- 옛 생각 루프는 **모두 얼린다.** 문이 "다음 차례"로 이어진 이웃의 상태를 **열쇠 한 칸 돌려서** 받는 통로를 더한다. 다음 차례 연결이 없으면 가지는 아무것도 더하지 않는다.
- 틀(사람이 줌): 열쇠 한 칸 돌리기, "한 쌍은 같음이면서 다음 차례일 수 없다", "문장 하나는 연결 하나를 말한다".
- 학습: 어느 문장이 다음 차례를 말하는지, 어느 쌍인지, 어느 방향인지.
- 정답 연결을 직접 넣어 주면 다음 차례 L=1 문제 300/300을 맞힌다. 열쇠 돌리기 통로는 완벽하다.

### 가지 학습: 실패 다섯 번과 해결 (seed 45, 학습 1,000문제)

| 시도 | 결과 | 원인 |
|---|---|---|
| 1. 132쌍을 따로 판단, 처음엔 모두 켜고 가지치기 | 다음 차례 0.20, 그대로 | 다 켜지면 열쇠가 사방에서 돌고, "같음과 동시 불가" 규칙이 기존 연결까지 지움 |
| 2. 시작값 낮춤, 학습 단계 늘림 | 그대로 (같은 값) | 연결 하나를 바꿔도 결과가 거의 안 바뀌어 단서가 없음 |
| 3. 읽기 부품 원래 머리에서 시작 | 연결 찾기는 됨, 점수 그대로 | 원래 머리는 쌍은 알지만 방향은 모름 → 양방향이 켜져 +1과 −1이 동시에 들어옴 |
| 4. "한쪽 방향만" 규칙 | 불안정 (켜졌다 꺼졌다) | 상관없는 쌍이 10% 켜져 기존 연결을 지움 |
| 5. 모든 문 정답 채점 | 그대로 | 같은 원인 |
| **6. 문장 하나 = 연결 하나 (관계 × 쌍 주의집중)** | **다음 차례 0.20 → 0.997, 기존 1.00 유지** | 쓸데없는 쌍이 켜질 여지가 구조적으로 없음 |

- 해결판은 질문한 문의 정답만으로도 배운다(30 epoch에서 0.997). 모든 문 채점은 필요 없다.
- 읽기 부품이 이미 아는 것: 원래 4칸 머리의 0번 칸("어느 쌍을 말하나", +1 vs −0.97)과 3번 칸("다음 차례인가", +1 vs −0.89). 방향은 768칸 안쪽에만 있다(탐침 1.0). 가지는 이 판단에서 출발해서 방향을 배운다.

## 본 실험: 예고 없이 바뀌는 문제 흐름 (`world8/stream.py`)

- 200문제짜리 구간 40개를 이어서 푼다. 문제마다 정답을 알려 준다.
  - 구간 1–10: 기존 표현만
  - 구간 11–20: 기존 50% + **새 말투** 50%
  - 구간 21–40: 기존 50% + **다음 차례** 50%
- **우리 시스템 (놀람으로 성장)**: 구간마다 "확신하고 답했는데 틀린 비율"(놀람)을 잰다. 놀람이 **2구간 연속 0.05를 넘으면** 성장을 결정한다. 그다음 5구간(1,000문제)을 공부 자료로 모으면서 계속 옛 부품으로 풀고, 모은 문제로 가지를 키워서 설치한다.
- 비교:
  - 절대 안 키움
  - **새로움으로 성장**: 문장이 처음 보는 종류인지(읽기 특징이 구간 1–5에서 본 문장들과 얼마나 먼지)를 재서, 새로운 문제 비율이 2구간 연속 0.05를 넘으면 같은 절차로 키운다. 키운 뒤에는 그때까지 본 문장을 "아는 것"에 더한다.
  - 이상적: 구간 21에 바뀐다는 것을 알고, 21–25를 모아 26부터 설치한다.

## 미리 적어 두는 판정 (생각 루프 seed 45–47)

  - (b) 구간 31–40의 점수가 이상적의 0.9배 이상이다.

- 함께 볼 것: 새로움으로 성장한 횟수(구간 11–20에서 쓸데없이 키우는지), 성장 시점, 키운 파라미터 수.

## 1차 실행과 수정 (2026-10-08)

- 1차(seed 45, 흐름 seed 45): 우리 신호는 "확신하고 답했는데 틀린 비율"(놀람)이었다. **한 번도 성장하지 않았다.** 놀람은 40구간 내내 0.0이었다. seed 45의 생각 루프는 다음 차례 문제에서 틀리지 않고 "모름"이라고 했기 때문이다. 사전 측정에서 seed 47만 확신하며 틀린 것을 일반화해서 신호를 정한 실수였다(`archive/world-v8_stream_seed-45_confident-wrong-signal.json`).
  - 같은 실행에서 새로움으로 성장은 4번 키웠다: 구간 12(새 말투, 낭비), 21, 26, 31. 이상적은 구간 22에 결정해 26부터 설치했고, 구간 31–40 점수는 0.9825였다.
- **수정: "실패율"로 바꾼다.** 실패 = 틀린 답, 또는 "모름"이라고 했는데 정답 공개 후 답이 있었던 경우다. 둘 다 정답을 본 뒤에야 알 수 있는 "내가 못 했다"는 신호다. 문턱(0.05, 2구간 연속)은 그대로다.
- 흐름을 이미 봤으므로 **최종 판정은 새 흐름**(흐름 seed = 생각 루프 seed + 1000)으로 한다. 판정 기준은 그대로다.

# 규칙 세계 v9: 새 능력의 모양까지 스스로 찾기 (2026-10-08)

## 분석 (실험 전 확인)

- **기울기로는 못 찾는다**: 가지의 열쇠 변환을 3×3 자유 행렬로 두고 "그대로 전달"(단위 행렬)에서 시작했다. 40 epoch 동안 행렬이 단위 행렬 근처에서 움직이지 않았다(대각 0.95–1.0). 다음 차례 점수도 0.2 그대로였다. 새 규칙은 이산적인데, 둘을 섞은 중간 상태는 더 나빠서 조금씩 고치는 학습이 처음 자리에 갇힌다.
- **가설을 세우고 시험하면 찾는다**: 열쇠 3개를 재배치하는 6가지를 가설로 놓고, 가설마다 가지를 짧게(20 epoch) 키워 학습에 안 쓴 문제로 점수를 매겼다. 한 칸 돌리기 하나만 0.815였고 나머지는 0.595였다.
- 기존 생각 루프는 맞바꿈(해↔별, 달 그대로)도 못 푼다: 0.23 / 0.19 / 0.18.
- 읽기 부품의 4칸 머리는 관계 중립 가설("B 열쇠는 A 열쇠에 따라 정해진다")에서도 문장이 말하는 쌍을 잡는다(같음, 새 말투, 다음 차례, 맞바꿈 모두 +1 vs −0.97). 하지만 관계 종류는 구별하지 못한다. 그래서 "내 담당 관계인가"(관계 문)는 중립에서 시작해 배운다.

## 오프라인 확인 (seed 45, 공부 자료 900, `world8/multibranch.py`)

| 자료 | 고른 모양 | 그 가설 | 나머지 5개 | 시험: 기존 / 새 말투 / 그 관계 |
|---|---|---:|---:|---|
| 다음 차례 | 한 칸 돌리기 [1,2,0] (방향은 반대로 학습해 같은 효과) | 0.995 | 0.595 | 1.000 / **0.880** / 0.983 |
| 맞바꿈 | **해↔별 [2,1,0]** | 0.985 | 0.645 | 1.000 / 0.997 / 0.953 |

- 두 관계 모두 정답 모양이 압도적으로 이겼다.
- **문제**: 다음 차례 가지가 새 말투 점수를 1.0에서 0.88로 떨어뜨렸다. 공부 자료에 새 말투가 없어서, 관계 문이 새 말투 문장 일부를 다음 차례로 받아들였다. → **복습**: 공부 자료에 지난 구간들의 문제를 섞는다.

## 본 실험: 새 관계가 두 번 나오는 흐름 (`world8/stream9.py`)

- 200문제 구간 50개. 1–10 기존 / 11–20 + 새 말투 / 21–35 + 다음 차례(50%) / 36–50 기존·새 말투·다음 차례·맞바꿈 각 25%.
- 성장 결정: 실패율이 2구간 연속 0.05를 넘으면(v8과 같음). 공부 자료 = 결정한 두 구간 + 다음 세 구간(1,000문제) + **복습: 지난 구간에서 뽑은 300문제**. 검증 100문제는 공부 자료에서 뗀다.
- 방식:
  - 안 키움
  - **모양 고정**: 사람이 준 모양(한 칸 돌리기)으로만 키운다. v8 방식이다.
  - **가설 탐색 (우리)**: 6가지 모양을 다 시험하고 고른다.
  - 정답 모양: 각 관계의 정답 모양을 알고 키운다(같은 시점, 같은 자료). 탐색의 상한이다.
- 흐름 seed = 생각 루프 seed + 2000 (새 흐름).

## 미리 적어 두는 판정 (seed 45–47)

- (a) 우리는 구간 1–20에서 키우지 않고, 21–35에서 한 번, 36–50에서 한 번, 모두 두 번 키운다.
- (b) 첫 성장에서 한 칸 돌리기(어느 방향이든), 두 번째에서 해↔별 맞바꾸기를 고른다.
- (c) 구간 46–50 점수가 정답 모양의 0.9배 이상이다.
- (d) 모양 고정보다 구간 46–50 점수가 0.1 이상 높다(seed 평균).
- (e) 구간 46–50에서 새 말투 문제 점수가 0.95 이상이다(복습 효과).

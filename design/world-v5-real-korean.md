# 사다리 5단계 "진짜 세상으로": 설계안 (초안)

작성일: 2026-10-08
상태: 설계 초안. 데이터 다운로드는 사용자 승인 후에 한다.

## 질문

만든 세계가 아니라 **진짜 한국어 글**에서도, "큰 부품은 얼려서 읽기만 시키고, 판단은 작은 학습 부품이 한다"가 **언어모델 단독**보다 나은가?

## 왜 이 과제인가

- 1–4단계의 공통 무기는 두 가지다. (1) 얼린 부품 위에서 연결을 학습한다. (2) 확실하지 않으면 "모름"이라고 말할 줄 아는 판단이다(+1 / 0 / −1 점수).
- 작은 언어모델이 실제 글에서 가장 자주 하는 실수는 **답이 글에 없는데도 그럴듯하게 지어내는 것**이다. 이건 우리 무기 (2)가 정면으로 겨냥하는 약점이다.
- 데이터는 **KLUE-MRC**(한국어 뉴스와 위키 지문, 사람이 만든 질문)를 쓴다. 이 데이터에는 **답이 지문에 없는 질문**이 들어 있다. 실제 글이고, 정답을 사람이 붙였고, 합성 조작이 없다.

## 시스템 (MK1의 실제 글 버전)

```
지문 + 질문
  ├─ 언어모델 LFM2.5-1.2B (얼림, 읽기 부품): 답 후보 문구를 뽑는다 + 그 문구의 확률
  ├─ mDeBERTa-NLI (얼림, 확인 부품): (후보가 나온 문장 주변, "질문 → 답은 X") 특징
  └─ 작은 판단 부품 (학습): [확인 특징, 후보 확률, …] → 답할까 / 모름
```

- 학습하는 것은 작은 연결 머리와 판단 부품뿐이다(1단계 방식). 정답 데이터는 KLUE-MRC 학습 세트에서 쓴다.
- 비교 대상(하나만): **언어모델 단독**. 같은 지문과 질문을 주고, 답이 없으면 "모름"이라고 하도록 지시한다.
- 참고 기준: 정답을 다 아는 기준선(항상 맞힘), 항상 "모름"(0점).

## 점수

- 답이 있는 질문: 맞으면 +1, 틀리면 −1, 모름이면 0. "맞음"은 정규화한 완전 일치 또는 글자 F1 ≥ 0.8이다(실험 전에 고정한다).
- 답이 없는 질문: "모름"이면 +1, 무엇이든 답하면 −1.

## 미리 적을 판정 (초안)

- 졸업: 시험 세트에서 MK1 점수 > 언어모델 단독 점수 + 0.05 (seed 3개, 95% 신뢰구간이 0보다 큼)
- 함께 볼 것: 답이 없는 질문에서 지어낸 비율, 답이 있는 질문에서 맞힌 비율, 학습 파라미터 수, 시간, VRAM

## 노트북 예산

- 언어모델 답 뽑기: 질문 약 6천 개 × 짧은 생성 → 약 30–40분 (한 번만 하고 캐시)
- NLI 특징: 후보 문장 주변만(≤ 128토큰) → 수 분
- 판단 부품 학습: 수 분

## 필요한 것 (사용자 승인)

- KLUE-MRC 데이터 다운로드 (Hugging Face `klue/klue`, mrc). 정확한 파일 크기는 승인 후 다운로드 전에 확인해서 알린다(수십 MB 예상). 라이선스는 CC BY-SA 4.0이다.

## 이번 단계에서 하지 않는 것

- 출처 신뢰나 물어보기는 하지 않는다. 실제 글에서 판단 구조가 통하는지를 먼저 확인한다.
- 어느 부품에 보낼지 학습(라우터)도 하지 않는다. 받아 둔 Julia-1(결정·라우팅 모델)은 다음 단계 후보다.

## 확정 (2026-10-08, 실험 전)

**데이터**: KLUE-MRC (28.7MB). 학습 3,000 / 검증 500은 KLUE train에서, 시험 2,000은 KLUE validation에서 뽑았다(고정 난수). 답 없는 질문 비율은 31–36%다.

**채점 규칙 수정**: 글자 F1은 "2013년"을 "2014년"의 정답으로 쳐서 버렸다. "맞음"은 공백과 문장부호를 지운 뒤 다음 중 하나다.
- 완전히 같다.
- 정답이 포함되고 더 붙은 글자가 3자 이하다.
- 정답의 일부이고 정답 길이의 60% 이상이다.

**언어모델 프롬프트**: 지시만 주면 문장 통째로 답했다. 그래서 시스템 지시와 직접 쓴 형식 예시 3개(KLUE가 아님, 모름 예시 포함)를 넣었다. 검증 60문제로 형식을 확인했다. 모름을 허용한 프롬프트로도 한 번도 모름을 하지 않았다(작은 모델의 특성).

**판정 기준 수정 (중요)**: 답 없는 질문이 31%라서 **무조건 "모름"만 해도 약 +0.31**이다. 그래서 "언어모델 단독보다 높기"는 아무것도 안 해도 통과하는 기준이다. 판정을 다음으로 바꾼다.
- **졸업**: MK1 점수 > max(무조건 모름, 언어모델 자기 확신 문턱) + 0.03 (seed 42–44 평균). 그리고 seed마다 짝 부트스트랩 95% 구간이 0보다 커야 한다.
  - 언어모델 자기 확신 문턱 = 후보 토큰의 평균 로그확률이 문턱보다 크면 답한다. 문턱은 검증 세트로 최적화한다.
- 함께 보고: 언어모델 단독(모름 허용 프롬프트), MK1에서 확인 부품을 뺀 것(확인 부품의 기여), 답 없는 질문에서 지어낸 비율, 완벽한 거르기 상한(후보가 맞을 때만 답함).
- MK1 판단 부품의 epoch는 검증 점수로 고른다.

## 결과 (2026-10-08): 미달

| | 점수 (시험 2,000) | 답한 비율 |
|---|---:|---:|
| 언어모델 단독 (모름 허용 프롬프트) | −0.553 | 98% |
| 무조건 모름 | 0.321 | 0% |
| 언어모델 자기 확신 문턱 | 0.319 | 0.3% |
| **MK1** (seed 42 / 43 / 44) | 0.321 / 0.326 / 0.323 | 3–7% |
| MK1에서 확인 부품을 뺀 것 | 0.321 | 0% |
| 완벽한 거르기 (상한) | 0.530 | 21% |

- MK1 − 가장 강한 비교 대상 = 0.000 / +0.005 / +0.0025. 부트스트랩 구간이 모두 0을 포함한다. **미리 정한 기준(+0.03)에 미달했다.**
- 언어모델 단독은 98% 답하고, 답 없는 질문에서도 지어낸다(−0.55). 판단 부품을 붙이면 지어내기가 거의 사라진다(답 없는 질문에서 답한 비율 1–3%). 하지만 무조건 모름보다 낫지는 않다.
- **원인: 읽기 부품(후보)의 질이 병목이다.** 1.2B 언어모델의 후보가 맞는 경우는 답 있는 질문의 31%(418/1,359), 전체의 21%다. 맞는 후보를 고르는 신호는 있다. 시험 AUC로 보면:
  - 언어모델 평균 로그확률 0.73, NLI 모순(부호 반대) 0.69
  - 답 없는 질문 가려내기: NLI 0.63, 언어모델 0.53
  - 하지만 기대 점수 규칙상 P(맞음)이 매우 높아야 답하는데, 이 정도 신호로는 그런 후보가 거의 없다.
- 교훈: **판단 부품은 읽기 부품이 가져온 것보다 나아질 수 없다.** 만든 세계에서는 읽기가 거의 완벽했지만, 진짜 글에서는 작은 언어모델의 읽기가 약하다. 확인 부품(NLI)은 "답 없음" 가려내기에 언어모델보다 나은 신호를 주지만, 그것만으로는 부족하다.

|---|---:|
| 지문 전체 (지금 방식) | 0.273 |

- 하지만 **완벽하게 검색해 줘도 1.2B 범용 언어모델은 42%를 틀린다.** 읽는 실력 자체가 약하다.
- e5 검색은 도움이 되지만(+0.07), 정답 문장을 고르는 비율이 65%라서 그것도 약하다.

## 5단계 2차: 읽기 전문가 키우기 (2026-10-08, 실험 전에 적음)

**읽기 전문가** (`world5/reader_qa.py`)
- mdeberta-v3-base에 답 위치(시작·끝) 머리를 붙여 KLUE-MRC로 학습한다. 학습 데이터는 KLUE train에서 우리 판단 학습 3,000문제와 검증 500문제를 뺀 **14,054문제**다. 그래서 판단 부품이 배우는 데이터에서 읽기 전문가의 출력은 처음 보는 데이터에 대한 출력이다. 시험 2,000문제는 KLUE validation에서 왔으므로 겹치지 않는다(코드로 확인).
- 답 없는 질문은 [CLS]를 가리키게 한다. 창은 384토큰, 겹침 128토큰이다. 2 epoch, lr 3e-5, bf16, gradient checkpointing.
- **버그 수정 (학습 전 발견)**: 빠른 토크나이저의 overflow 기능이 넘친 부분을 한 번만 잘랐다. 1,183토큰 지문이 창 2개로 끝나서 지문 뒷부분을 읽지 못했다(답 있는 문제의 23%가 어떤 창에도 정답이 없었다). 창 나누기를 직접 구현했다. 고친 뒤 400문제 표본에서 답 있는 276문제 모두 정답이 창 안에 있고, 정답 위치 라벨 344개를 풀어 보면 모두 정답 규칙상 맞다.

**MK1 v2** = 읽기 전문가(얼림) + NLI 확인 부품(얼림) + 작은 판단 부품. 판단 부품의 입력은 답 점수, 답 없음 점수, 둘의 차이, 답 길이, NLI 특징이다.

**판정 (seed 42–44)**
- (1) **전문가 조합 > 범용 언어모델**: MK1 v2 점수 > 언어모델 단독 점수, 그리고 > 1차 MK1(0.32). 짝 부트스트랩 95% 구간 > 0.
- (2) **판단 부품의 기여**: MK1 v2 > 읽기 전문가 단독(답 점수 − 답 없음 점수에 문턱을 두고, 문턱은 검증으로 최적화) + 0.01. seed마다 부트스트랩 95% 구간 > 0.
- (1)과 (2)를 모두 만족하면 졸업. (1)만 만족하면 "전문가가 이기지만 판단 부품은 값을 더하지 않음"으로 기록하고 다음 방향을 정한다.

## 2차 결과 (2026-10-08)

**읽기 전문가 단독 실력** (답 있는 질문에서 후보가 맞는 비율): 시험 **0.726** (987/1,359), 검증 0.668. 범용 언어모델 지문 전체 0.31, 정답 문장만 줘도 0.58이었다. 학습은 사용자가 실행했다(약 1시간).

| | 시험 점수 | 답한 비율 | 답 없는 질문에서 지어냄 | 답했을 때 맞힘 |
|---|---:|---:|---:|---:|
| 범용 언어모델 단독 | −0.553 | 98% | 대부분 | |
| 무조건 모름 | 0.321 | 0% | 0% | |
| 1차 MK1 (언어모델 후보) | 0.321–0.326 | 3–7% | 1–3% | |
| **읽기 전문가 단독** (답 없음 점수 문턱) | **0.471** | 35% | 10.1% | 76.1% |
| **MK1 v2** (seed 42 / 43 / 44) | 0.476 / 0.464 / 0.469 | 37–39% | 12–14% | 74–76% |
| 완벽한 거르기 (상한) | 0.814 | | | |

- **(1) 전문가 조합 > 범용 언어모델: 통과.** MK1 v2 − 언어모델 단독 = +1.02 (부트스트랩 [+0.97, +1.07], seed 3개 모두). 1차 MK1(0.32)보다도 +0.15 높다.
- **(2) 판단 부품의 기여: 미달.** MK1 v2 − 읽기 전문가 단독 = +0.0045 / −0.0075 / −0.0025. 구간이 모두 0을 포함한다. NLI 확인 부품과 학습한 판단은 잘 학습된 읽기 전문가의 "답 없음" 점수 위에 더하는 것이 없다.
- 판정 규칙에 따라 기록한다: **"전문가가 이기지만 판단 부품은 값을 더하지 않음."**
- 해석:
  - 2.8억 파라미터 전문가가 12억 파라미터 범용 모델보다 훨씬 잘 읽는다(0.73 vs 0.31). 사용자의 처음 생각("각각에 최적화된 모델")이 실제 글에서 맞았다.
  - 한 가지 일(읽고 답하기)에서는 잘 학습된 전문가가 자기 확신(답 없음 점수)을 이미 갖고 있다. 바깥 판단 부품이 더할 여지가 거의 없다.
  - 오케스트레이션(조합과 연결)의 가치는 1–4단계처럼 **여러 능력을 합쳐야 하는 문제**에서 나온다. 한 능력 안에서는 나오지 않는다.

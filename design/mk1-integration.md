# MK1 통합

작성일: 2026-10-08

## 목표

1–9단계에서 각자 다른 세계로 키운 부품들을 **겉은 하나, 속은 여러 개**인 시스템으로 묶는다. 밖에서는 문제를 넣으면 답이 나오는 시스템 하나다. 안에서는 부품이 나뉘어 있어서 하나씩 키우고, 얼리고, 갈아 끼울 수 있다(4단계: 전부 다시 학습하면 예전 능력이 망가졌다).

## 지금 부품들이 바로 안 합쳐지는 이유

1. 미리 계산한 특징 표에 묶여 있어서 표에 없는 문장을 못 읽는다.
2. 부품마다 메시지 형식이 다르다.
3. 세계마다 문 수, 사람 유무 같은 설정이 다르다.
4. 기억 범위가 다르다(세션 내내 vs 문제 하나).

## 설계 원칙: 공용 칠판 = 주소는 구조로, 내용은 학습으로

칠판의 한 줄은 [주소: 누가, 무엇에 대해, 종류] + [내용: 학습된 메시지] + [메모: 쓴 부품, 시각]이다. 1단계에서 사람이 정한 칸만 넘기면 정보(말투)가 버려졌고, 문장을 벡터 하나로 만드는 완전히 자유로운 방식은 학습이 안 됐다. 성공한 것은 "대상은 구조로 고정하고 내용은 학습"하는 방식이었다. 칠판도 같은 원칙을 따른다.

## 순서

- **A. 바탕 공사**: 실시간 읽기, 부품 명함, 자동 졸업 시험 ← 완료 (아래)
- **B. 칠판 연결**: 칠판과 부품별 읽기·쓰기 어댑터. 칠판을 거쳐도 각 단계 점수가 그대로인지 확인(동등성 검사). 읽기 전문가를 fp32로 바꾼다.
- **C. 통합 시험**: 한 세계, 한 시스템, 섞인 문제(신뢰, 고리, 복합, 물어보기, 새 관계). 종류마다 각 부품의 졸업 점수를 유지하는지(±0.02), 사령탑이 맞는 부품을 부르는지, 성장이 통합 상태에서도 되는지, 속도(초당 문제 수, 메모리)를 잰다.
- **D. 나중에**: 실제 한국어 글 부품(읽기 전문가, 실제 글 신뢰)을 전문가처럼 칠판에 끼운다.

## B 결과 (2026-10-08): 칠판 연결

**B1. 칠판** (`mk1/board.py`): 부품끼리 서로 부르지 않고 이름 붙은 칸에 쓰고 읽는다. 칸 주소는 구조로 정해져 있고(무엇에 대한 칸인지), 내용은 부품이 낸다. 쓸 때마다 누가 어느 칸에 썼는지 기록돼서 한 번의 풀이를 따라가 볼 수 있다.

| 칸 | 내용 | 쓰는 부품 → 읽는 부품 |
|---|---|---|
| `reading.trust` | 사람 말 × 기준 문 × 열쇠의 읽기 특징 (실시간) | 읽기 → 신뢰 |
| `reading.board` | 안내판 문장 × 가설 102개의 읽기 특징 (실시간) | 읽기 → 생각 |
| `trust.door_logits` | 기준 문마다 열쇠 확률 | 신뢰 → 연결 |
| `thinker.first` | 생각 1차: 답, 문마다 믿음, 연결 | 생각 → 사령탑 |
| `router.asked` | 물어볼 기준 문 | 사령탑(또는 고정 규칙) → 연결 |
| `facts.from_trust` | 물어본 문의 결론을 생각 부품의 사실 메시지로 | 연결 → 생각 |
| `answer.logits` | 최종 답 (0.5 못 넘으면 모름) | 생각 → 밖 |

- 신뢰 부품이 읽는 가설("빨간 문은 해 열쇠로 열린다.")과 생각 부품의 사실 가설이 글자까지 같다. 같은 읽기를 두 부품이 함께 쓴다.

**B2. MK1 본체** (`mk1/system.py`): 저장된 부품을 그대로 불러온다. 바뀐 건 배선뿐이다. 부품은 학습 때 쓰던 미리 계산한 표를 불러오지 않고, 칠판에 올라온 실시간 읽기만 쓴다. 방식은 네 가지다.

| 방식 | 하는 일 | 해당 단계 |
|---|---|---|
| 신뢰만 | 신뢰 부품이 기준 문에 답 | 1단계 |
| 생각만 | 안내판만 보고 생각 | 3단계 |
| 다 묻기 | 기준 문 셋 모두 신뢰 부품에 묻고 생각 | 4단계 |
| 사령탑 | 생각 1차 → 사령탑이 모자란 것만 물음 → 생각 2차 | 7단계 |

**B3. 칠판 동등성 검사** (`python -m cognitive_lab.mk1.checks board`): MK1 하나로 각 단계 시험을 다시 풀었다.

| 시험 | 졸업 점수 | 칠판을 거친 MK1 |
|---|---:|---:|
| 1단계 신뢰 + 말투 | 0.4148 | 0.4148 |
| 3단계 생각 | 0.9750 | 0.9750 |
| 4단계 연결 | 0.4485 | 0.4485 |

- **읽기 기억**: 실시간 읽기는 초당 약 600쌍이고, 시험 전체에 약 23만 쌍이 필요하다(첫 실행 약 8분). 그래서 읽은 결과를 `artifacts/cache/mk1-reading-memory.pt`(약 360MB)에 기억해 둔다. 같은 얼린 모델이 fp32로 읽은 값이라 실시간 읽기와 같다. 두 번째 실행부터는 칠판 시험 4개가 합쳐서 약 11초 걸린다(전체 졸업 시험 약 1분).

- 2단계(물어보기)는 세계와 주고받는 동작이 필요해서 C에서 칠판에 올린다. 5·6단계(실제 글)는 D에서 다룬다.

**B4. 읽기 전문가 fp32**: `Reader`가 이제 기본으로 fp32로 읽는다(bf16에서는 같이 묶인 문제에 따라 답이 바뀌었다). v5·v6 캐시는 bf16으로 만들었으므로, 캐시에 이어 쓰는 `world6/reports.py`는 `precise=False`로 같은 방식을 유지한다.

## C. 통합 시험 설계 (2026-10-08, 돌리기 전에 적음)

**세계**: 한 묶음에 문제 종류를 섞는다. MK1에게 종류는 알려주지 않는다.
- 7단계 시험 세션 100개 × 40문제: T(사람들이 말한 문을 물음), C(사슬 끝을 물음, 안내판이 기준 문 열쇠를 알려줌), TC(사슬 끝을 물음, 기준 문 열쇠는 사람 말로만 알 수 있음)
- 3단계 시험 문제 3,000개: 안내판만 있고 말하는 사람이 없음. 사슬이 더 길고(1–6칸), 답이 없는 문제(모름이 정답)도 섞임

**MK1 설정 하나로 전부**: 사령탑 방식 + 호기심 켬 + "아무도 말 안 했으면 신뢰 부품에 묻지 않기" 규칙.
- 호기심은 질문 문이 기준 문일 때만 사람에게 물을 수 있다. 사람들은 기준 문 이야기만 하기 때문이다. 묻는 비용은 0.2, 사령탑이 신뢰 부품에 묻는 비용은 0.05다.

**미리 정한 졸업 기준**
1. **섞어도 안 깨짐**: 호기심을 끄면 종류별 점수가 각 단계 점수와 같아야 한다(허용 오차 0.002). 기준값은 T 0.3926, C 1.0, TC 0.4109, 안내판만 0.975다.
2. **물어보기가 전체 안에서도 이득**: 호기심을 켜면 T 순점수(비용 뺀 점수)가 끈 것보다 높아야 한다. 짝지은 부트스트랩 95% 구간이 0 위에 있어야 한다. C·TC·안내판만은 0.01 넘게 떨어지면 안 된다.
3. **속도 기록**: 읽기 기억이 찬 상태에서 초당 문제 수와 GPU 최대 메모리를 잰다. 처음 읽는 비용(초당 읽기 쌍)도 따로 적는다. 기준값은 없고, 나중에 최적화할 출발점이다.

**진단**(졸업 기준 아님): "아무도 말 안 했으면 묻지 않기" 규칙을 끄면, 안내판만 있는 문제에서 사령탑이 빈 신뢰 부품에 묻는다. 그때 얼마나 망가지는지 잰다.

## C 결과 (2026-10-08): 졸업

`python -m cognitive_lab.mk1.integration` → `artifacts/results/mk1-c_integration.json`. 문제 7,000개(T 1,351 / C 1,308 / TC 1,341 / 안내판만 3,000)를 섞어서 한 목록으로 넘겼다.

| 종류 | 단계 점수 | 호기심 끔 | 호기심 켬 | 차이 (95% 구간) |
|---|---:|---:|---:|---|
| T | 0.3926 | 0.3926 | **0.5128** | +0.120 (+0.094, +0.149) |
| C | 1.0 | 1.0 | 1.0 | 0 |
| TC | 0.4109 | 0.4109 | 0.4131 | +0.002 (−0.005, +0.009) |
| 안내판만 | 0.975 | 0.975 | 0.975 | 0 |

- **기준 1 통과**: 섞어도 종류별 점수가 단계 점수와 똑같다.
- **기준 2 통과**: 사람에게 더 물어보기가 전체 시스템 안에서도 이득이다. T에서 문제당 0.38번 묻고, 비용 0.2를 빼고도 +0.12다. 2단계 혼자일 때(0.4148 → 0.5311, +0.116)와 비슷한 크기다.
- **덤**: TC에서는 사람에게 묻지 못하는데도(질문 문이 기준 문이 아님) 조금 올랐다(+0.002, 구간이 0을 포함함). T에서 더 물어 들은 말이 "누가 맞는지" 기억을 낫게 만들어서, 같은 세션의 뒤 문제에 도움이 됐을 수 있다. 부품끼리 칠판을 통해 간접적으로 돕는 첫 신호인데, 아직 확실하지는 않다.
- **진단 (묻지 않기 규칙 끔)**: 안내판만 있는 문제에서 사령탑이 문제당 0.14번 빈 신뢰 부품에 묻는다. 점수는 0.975 → 0.9705인데, 떨어진 만큼이 거의 그대로 묻는 비용이다(0.14 × 0.05 = 0.007). 빈 신뢰 부품은 "모르겠음"을 전달할 뿐이라 답을 망치지는 않았다. 돈만 낭비한다.

**속도 (RTX 5070 노트북 GPU)**

| 항목 | 값 |
|---|---|
| 생각·판단 부품들 (읽기 기억이 찬 상태) | 초당 약 1,800–2,000문제 |
| GPU 최대 메모리 (작은 부품 + 문제 7,000개 한 번에) | 약 1.2GB |
| 처음 보는 문장 읽기 (얼린 읽기 부품, fp32) | 초당 약 570쌍 |

- **병목은 읽기다.** 처음 보는 안내판 문장 하나를 읽으려면 가설 102개와 짝지어 읽어야 하니 약 0.18초가 걸린다. 문제 하나에 새 문장이 6개면 약 1초다. 생각·판단은 문제당 0.5밀리초라서, 읽기가 약 2,000배 느리다.
- 그래서 최적화 순서는 읽기가 먼저다. 문장에 나온 문·열쇠와 관련된 가설만 읽으면 102개가 5–10개로 준다. 그다음이 bf16(결과가 바뀌는지 꼭 확인), 마지막이 문장 하나를 한 번만 인코딩하는 구조다.

## 읽기 최적화 (2026-10-08)

**기준**: 칠판 졸업 시험 5개(1·2·3·4·7단계)가 0.002 안에서 그대로여야 한다.

**1. 관련 가설만 읽기** (`mk1/relevance.py`): 문장마다 문이 1–2개만 나온다. 안 읽은 칸에는 채움값(학습용 문장 300개에서 구한 "상관없는 문장"의 평균 특징)을 넣었다.

| 읽는 방식 (안내판 문장당 읽는 수) | 3단계 점수 |
|---|---:|
| 전부 (102) | 0.975 |
| 관련 사실 + 관련 쌍 (3–7) | 0.956 ✗ |
| 관련 사실 + 쌍 전부 (69–72) | 0.956 ✗ |
| **사실 전부 + 관련 쌍 (36–37)** | **0.975** |

- 생각 부품은 문장에 안 나온 문의 사실 가설 읽기까지 쓴다. "아무도 이 문 얘기는 안 했다"의 잡음 수준(여러 문장 읽기 중 최댓값)이 기준선이 되는데, 평균 채움값 하나로는 그걸 흉내 낼 수 없다. 쌍 가설은 관련 있는 것만 읽어도 된다.
- 사람 말(신뢰 부품)은 9개(문 3 × 열쇠 3)를 다 읽어야 했다. 이름 나온 문의 3개만 읽었더니 1단계 0.4140, 2단계 0.5278(−0.003)으로 떨어졌다.
- 한계: 문 찾기는 문 이름 글자 맞추기다. 만든 세계에서만 통하는 손 규칙이라, 실제 글에서는 "이 문장이 무엇에 대한 것인지"를 배워야 한다.

## F. 출처 충돌: 부품을 믿는 법 배우기 (2026-10-08, 돌리기 전에 적음)

**원리**: 1단계 신뢰 부품은 "누가 자주 맞았는지" 기억해서 **사람**을 저울질했다. 같은 원리를 한 단계 위로 올려서, **정보 통로(안내판, 기사 부품)**를 저울질하는 중재자를 만든다.

**세계 v11** (`world10/world.py`에 `board_accuracies` 추가): v10과 같은데, 세션마다 안내판 신뢰도 r ∈ {1.0, 0.75, 0.5}가 숨겨져 있다. C 문제에서 안내판이 기사 문의 열쇠를 말하는데, 확률 r로 맞고 아니면 다른 열쇠를 말한다. 정답(기사 문의 진짜 열쇠)은 문제마다 공개된다. A·AC는 v10과 같다(안내판이 기사 문에 대해 말하지 않음).

**중재자** (새 부품, `mk1/arbiter.py`):
- 입력: 기사 문에 대해 통로마다 [말했나, 말한 열쇠(확실하면)]. 안내판 통로는 생각 부품의 1차 생각(안내판만 봄)에서, 기사 통로는 실제 글 신뢰 부품의 결론에서 온다.
- 통로마다 기억(GRU)을 둔다. 문제가 끝나면 [말했나, 맞았나, 틀렸나]로 갱신한다.
- 출력: 열쇠 3개 + 모름. 신뢰 부품과 같은 구조라서, 열쇠와 통로에 대해 같은 가중치를 공유하고 통로 이름은 쓰지 않는다.
- 결론은 생각 부품에 **합치기 대신 바꾸기**로 넣는다(그 문의 사실 메시지를 중재자 결론으로 바꿈). 생각 부품의 가중치는 그대로이고, `think(extra_replace=True)`라는 배선 옵션만 추가한다.
- 학습: v11 학습 세션 600개. 기사 읽기는 v6 캐시(bf16)를 쓴다(D2에서 실시간 fp32와 점수가 같음을 확인). 정답 열쇠에 대한 교차 엔트로피로 배운다. 시험은 실시간 fp32 읽기로 한다.

**비교**: 안내판만 / 기사만 / 합치기(지금 방식) / 중재자 / 세션마다 더 나은 통로를 미리 아는 길잡이. 모두 기사에 묻는다(비용 0.05). 안내판만은 묻지 않는다.

**미리 정한 기준**
1. 중재자가 합치기보다 전체 점수가 높다. 짝지은 95% 구간이 0보다 크다.
2. 안내판 신뢰도마다 중재자 ≥ max(안내판만, 기사만) − 0.01. 믿을 만한 안내판을 망치지 않고, 나쁜 안내판에 속지 않는다.
3. 세션 안에서 배운다: r = 0.5 세션의 C 문제에서 뒤쪽 절반 점수 − 앞쪽 절반 점수의 95% 구간이 0보다 크다.
4. A·AC(충돌 없음)에서 중재자 점수가 기사만 점수와 0.01 안이다.

## I. 경험 밖에서도 무너지지 않는 믿음 (2026-10-08, 판정 전에 적음)

**문제 (감사 8절)**: 학습한 중재자는 안내판 신뢰도 1.0/0.75/0.5만 경험했다. 처음 보는 0.25(무작위보다 나쁨)에서 실패했다. 기억(GRU)이 경험한 범위 안에서만 의미를 갖기 때문이다.

**아이디어: 예시를 늘리는 대신 표현을 바꾼다.**
- **세는 중재자** (`CountingArbiter`): 통로마다 이번 세션에 "말한 횟수, 맞은 횟수"를 센다. 신뢰도는 베타 분포 사후 평균 (맞음 + α) / (말함 + α + β)로 추정한다. 그 통로가 열쇠 k를 말하면 k는 신뢰도 배, 다른 열쇠는 (1 − 신뢰도)/2배로 가중한다.
- 그래서 신뢰도가 0이든 1이든 같은 계산이 통한다. 무작위보다 나쁜 통로(1/3 미만)는 자기가 말한 열쇠를 오히려 깎는다.
- **사전 믿음만 경험에서 배운다**: α, β 두 숫자다. 모든 통로가 공유하니 통로 이름을 쓰지 않는다. 학습한 중재자와 똑같은 학습 데이터(신뢰도 1.0/0.75/0.5, 600세션)에서 맞춘다.

**이미 본 시험 세계에서 잰 효과 크기** (seed+200 세계, 문 점수): 사전분포는 Beta(약 4, 1.7), 즉 처음엔 약 70%를 믿는다.
- 학습 때 본 신뢰도에서는 학습한 중재자와 비슷하다(±0.01 안팎).
- 처음 보는 0.25/0.1에서 학습한 중재자는 −0.06~+0.07이고, 세는 중재자 + 사전은 +0.06~+0.11이다.
- 아주 낮은 신뢰도에서는 기사만 쓰는 것(+0.11~+0.18)보다 아직 낮다. 나쁜 안내판이라는 증거가 쌓이는 데 몇 문제가 걸린다.

**최종 판정은 새 시험 세계(seed+300)에서, seed 42/43/44, 세션 단위 구간으로 한다.** 안내판 신뢰도는 학습 때 본 1.0/0.75/0.5와 처음 보는 0.9/0.6/0.25/0.1을 섞는다. 점수는 생각 부품을 거친 최종 순점수다.

**미리 정한 기준**
1. **경험 밖 (0.25, 0.1)**: 세는 중재자 + 사전 − 학습한 중재자의 세션 단위 95% 구간이 0보다 크다. seed 3개 모두.
2. **경험 안 (1.0, 0.75, 0.5)**: 세는 중재자 + 사전 ≥ 학습한 중재자 − 0.02. seed 3개 모두.
3. **해롭지 않음**: 모든 신뢰도에서 세는 중재자 + 사전의 점수가 "안내판만"과 "기사만" 중 낮은 쪽 이상이다. seed 3개 모두.

**솔직한 점**
- 학습한 중재자는 처음 보는 낮은 신뢰도에서 **음수**로 떨어진다(안내판을 믿어서 손해). 세는 중재자는 모든 신뢰도에서 0 이상이고, 기준 3(단일 통로 둘 중 낮은 쪽 이상)도 통과했다.
- 아주 낮은 신뢰도(0.25, 0.1)에서는 **기사만 쓰는 것보다 아직 낮다**(예: 0.016 vs 0.075). 세션 초반에는 사전 믿음(70%)대로 안내판을 믿다가, 나쁜 안내판이라는 증거가 쌓여야 바뀐다. 이건 "빨리 의심하기"의 문제로 남는다.
- 세는 방식의 계산 구조(베타 분포, 열쇠 가중)는 사람이 설계했다. 배운 건 사전 믿음 숫자 2개다. 그래서 "경험 밖으로 넘어가는 힘"의 상당 부분은 **표현을 잘 고른 데서** 나온다. 학습만으로 생긴 게 아니다.

**결정**: 기록 재현을 위해 F·G·H 스크립트는 학습한 중재자를 그대로 쓴다. 앞으로 새 실험의 기본은 **세는 중재자**(`MK1(arbiter="counting")`)다. 경험 안에서 −0.01 손해가 있지만, 경험 밖에서 무너지지 않는 쪽을 고른다.

## K. 예상 못 한 변화 알아채기 (2026-10-09, 판정 전에 적음)

**근거**: Yu & Dayan의 예상된/예상 못 한 불확실성(`design/neuroscience-review-2026-10-09.md` 4절). 세는 중재자는 "이 통로는 원래 70%"(예상된 불확실성)만 다룬다. 믿던 통로가 갑자기 나빠지는 걸 알아채는 장치가 없다.

**장치** (`ChangeArbiter`): 통로마다 베이즈 온라인 변화점 검출(Adams & MacKay 2007)을 한다. "마지막 변화 이후 몇 번째인가"의 분포와, 구간마다 Beta 통계를 둔다. 학습한 사전 믿음은 세션 첫 구간에만 쓰고, 변화 뒤에 시작하는 구간은 Beta(1,1)로 시작한다. 학습할 숫자는 α, β, 변화율 h 세 개다.

**세계**: v11에 `switch` 옵션을 넣었다. 10–30번째 문제 사이 숨은 시점에 안내판 신뢰도가 한 번 바뀐다. `switch_to`로 바뀔 수준을 정한다(배신: 1.0/0.75 → 0.25 또는 0.1).

**개발 중 배운 것 (개발용 세계 seed 242, 문 점수)**
1. 약한 변화(1.0 ↔ 0.75 ↔ 0.5)만 있는 세계에서는 효과가 0이다. 현재 신뢰도를 아는 길잡이도 +0.025뿐이다. 바뀌어도 결정이 거의 안 바뀌기 때문이다.
2. 변화 뒤 새 구간도 학습한 강한 사전 믿음으로 시작하면, 배신한 안내판을 오래 따른다. → 변화 뒤 구간은 Beta(1,1)로 시작한다.
3. 약한 변화만 있는 학습 데이터에서 h를 맞추면 h ≈ 0.001, 즉 변화 감지를 꺼 버린다. 배신을 겪어 본 적이 없으면 대비할 이유가 없다. → **학습 경험**을 바꿨다. 학습 세션은 변화 없음 / 약한 변화 / 배신(→0.25)을 1/3씩 섞는다. 그러자 h ≈ 0.033이 학습됐다. 비교 상대인 세는 중재자도 같은 데이터로 맞춘다.

| 개발용 세계 (문 점수) | 세는 | 변화 감지 | 길잡이 |
|---|---:|---:|---:|
| 배신 → 0.25 | 0.155 | 0.175 | 0.239 |
| 배신 → 0.1 (학습 때 없던 수준) | 0.121 | 0.160 | 0.246 |
| 약한 변화 | 0.249 | 0.249 | 0.273 |
| 변화 없음 | 0.272 | 0.269 | 0.284 |

**판정**: 새 시험 세계(test seed + 300), 부품 seed 42/43/44(중재자도 seed마다 따로 맞춤), 생각 부품을 거친 최종 순점수, 세션 단위 95% 구간.

**미리 정한 기준**
1. **배신**(→0.25와 →0.1을 합침): 변화 감지 − 세는 중재자의 세션 단위 구간 하한 > 0. seed 3개 모두.
2. **변화 없음, 약한 변화**: 변화 감지 ≥ 세는 중재자 − 0.01. seed 3개 모두.
3. 진단(기준 아님): 배신 10문제 뒤부터의 C 점수, 길잡이와의 차이.

- **기준 1 통과**: 배신 세계에서 셋 다 구간이 0보다 크다. 학습 때 없던 더 심한 배신(→0.1)에서 효과가 더 크다.

- 세는 중재자는 배신당한 뒤에도 −0.3 수준으로 거짓말쟁이를 따른다. 변화 감지는 0 근처까지 회복한다. 길잡이(개발용 세계 기준 +0.2)와의 남은 차이는 알아채는 데 드는 몇 문제와, 안내판만 말할 때 "거꾸로 쓰기"만으로는 0.5를 넘기기 어려운 데서 나온다.

**배운 것**: 장치(변화점 검출)만으로는 부족했다. **변화를 겪어 본 경험**이 있어야 변화율이 의미 있게 학습됐다(약한 변화만 겪으면 h ≈ 0.001). 사전 믿음과 대비 수준은 경험이 정한다.

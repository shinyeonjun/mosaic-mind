# 규칙 세계 v2-H: 말투 단서 (사다리 1단계 졸업 시험)

작성일: 2026-10-07
관련: [통합 시스템 v1](integrated-system-v1.md), [규칙 세계 v2](world-v2-learning-to-judge.md)

## 질문

통합 시스템("완성형 시스템")은 v2에서 "사람이 정한 칸 + 학습 판단기"와 같은 점수였다. 칸이 정보를 하나도 버리지 않는 세계였기 때문이다.
그러면 **칸에 들어가지 않는 정보가 있을 때, 스스로 배운 연결이 그 정보를 꺼내 써서 칸 방식을 이기는가?**

## 세계

- 표준 v2 세션을 그대로 쓴다. 사람, 정확도, 주장, 문장은 똑같고, 별도의 난수로 문장 앞에 말투만 붙인다(코드로 확인).
- 말투는 세 가지다: 확신("확실한데, ", "내가 직접 봤어. ", "틀림없어. "), 보통(앞말 없음), 망설임("잘은 모르겠는데, ", "들은 얘기라 확실하진 않은데, ", "기억이 가물가물한데, ").
- P(말투 | 맞는 말) = 0.45 / 0.40 / 0.15, P(말투 | 틀린 말) = 0.15 / 0.40 / 0.45. 우도비는 3, 1, 1/3이다.
- 말투는 말하는 사람과 무관하다. 정정 전에 한 말에는 정보 없는 말투를 붙이고, 잡담에는 붙이지 않는다.
- 구현: `world2/hedged.py`. 다른 문의 정답은 `hidden_other_truths`에 저장하고, 점수판이 판단기에게서 가린다.

## 확인한 사실 (실험 전)

| 시험 세트 seed | 정답 아는 기준선 | +말투 | 수학 공식 학습자 | +말투 | 칸 + 학습 판단기 |
|---|---:|---:|---:|---:|---:|
| 42 | 0.419 | 0.476 | 0.351 | **0.418** | 0.350 |
| 43 | 0.445 | 0.490 | 0.380 | **0.438** | 0.378 |
| 44 | 0.460 | 0.508 | 0.396 | **0.448** | 0.394 |

- 말투를 쓰지 않는 기준선은 v2와 정확히 같다(0.4193, 0.351). 바탕 세계가 바뀌지 않았다는 뜻이다.
- 말투의 가치는 이상적인 학습자 기준 약 **+0.06**이다.
- 칸 방식의 NLI 파서는 말투가 붙은 문장도 100% 정확하게 읽는다(주장 2,202/2,202, 잡담 552/552, seed 42 세션 10개). 그러므로 칸 방식이 잃는 것은 말투 정보뿐이다.
- 선형 탐침(문장을 기준으로 나눈 평가 세트): v1 읽기 부품의 4차원 메시지로 말투를 맞힌 정확도는 0.430으로, 최빈값 0.43과 같다. 768차원 내부 특징으로는 0.971이다. **정보는 부품 안에 있지만 원래 연결에서는 버려진다.**

## 시스템

- 읽기 부품 본체는 고정한다. (문장, 문, 열쇠) 13,680쌍의 768차원 특징을 fp32로 한 번만 계산한다. v1 머리로 재현한 결과와 기존 캐시의 차이는 최대 1.8e-7이다.
- **연결 머리**: 768 → 8 선형 + tanh. 0–3행은 v1 머리에서 시작하고, 4–7행은 0 근처에서 시작한다. 최종 답만으로 학습한다(말투 라벨 없음).
- 기억과 판단: 통합 시스템과 같다. 학습 세션 3,000개, 30 epoch, 검증 점수로 epoch를 고른다.
- 점수판 에이전트로 재채점한 점수가 배치 점수와 같아야 한다(코드로 강제).

## 미리 적어 두는 예상과 판정

- **졸업**: seed 3개 모두에서 연결 시스템이 칸 + 학습 판단기보다 높고, 평균 이득이 +0.03 이상이다(말투 가치의 절반).
- **부분 성공**: 이득이 0보다 크지만 +0.03보다 작다. 이 경우 연결 머리가 말투를 일부만 꺼낸 것이다. 탐침으로 메시지 4–7번 차원을 확인한다.
- **실패**: 이득이 0 근처다. 이 경우 최종 답만으로는 신호가 너무 약하다. 다음 조치를 하나만 정한다(예: 머리 학습률).

## 결과 (2026-10-08): 졸업

| seed | 칸 + 학습 판단기 | **연결 머리** | 말투만 지움 | 이상적 학습자 (말투 앎) |
|---|---:|---:|---:|---:|
| 42 | 0.350 | **0.415** | 0.354 | 0.418 |
| 43 | 0.378 | **0.426** | 0.367 | 0.438 |
| 44 | 0.394 | **0.445** | 0.394 | 0.448 |

- 이득은 +0.065, +0.049, +0.051이다. 평균 **+0.055**, 95% CI는 [+0.033, +0.077]이다. 미리 정한 졸업 기준(3개 모두 양수, 평균 ≥ +0.03)을 통과했다.
- **원인 확인**: 시험할 때 메시지를 말투를 뗀 같은 문장의 메시지로 바꾸면 점수가 칸 방식 수준으로 돌아간다. 이득은 전부 말투에서 왔다.
- **탐침** (각 문장이 말하는 쌍, 학습에 쓰지 않은 문장): 부품 안쪽 1.00, v1 4칸 메시지 0.42(찍기 수준), 새 8칸 메시지 0.49 / 0.76 / 0.78. seed 42는 긍정 문장과 부정 문장을 따로 보면 0.76 / 0.99다. 말투를 극성과 섞인 방향으로 담았다.
- 배치 점수와 점수판 재채점이 일치했다. 학습 파라미터는 연결 머리 6,152개, 기억·판단 19,361개다. seed 하나에 약 32분, GPU 메모리 1GB 미만이었다.
- 구현: `world2/hedged_system.py`, 분석: `world2/hedged_analysis.py`.
